# 持续文本模块依赖

来源：2026-11-07 D11学生最终实现；token_prefix_length、after_delimiter均经多轮提示后完成，非无提示独立成果。教师仅接入共享头文件依赖。四份文件按原字节复制，避免后续课程重抄旧函数。作为后续命令原型持续依赖保留，不按日课独立源清理。

- token_prefix_length：显式可读范围内扫描到指定分隔符或结束符，范围耗尽返回范围长度；零容量不访问。
- after_delimiter：正范围要求完整字符串结束符在范围内，返回首分隔符后的原数组地址；未找到/零范围/结束符分隔符返回NULL，找到末尾分隔符可返回有效空字符串地址。
- 借用地址不延长原数组寿命，不修改原数组；返回值不可通过const访问路径写入。
- 这些.c没有main；调用程序链接两份实现，不把源码复制进学生核心。
