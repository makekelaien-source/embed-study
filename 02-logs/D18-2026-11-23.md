## 实授补页｜筛选对下一次读取的影响

课堂先用三行温度（22、35、18）区分“读了几条”和“匹配了几条”。每个数组元素是一条独立记录；即使一条记录的两个选中位都开启，该记录也只为计数贡献 1。数组形参传入首元素地址，有效记录数由调用者传入。对于空数组，两种查询的返回值都是 0，此时不访问元素。空掩码另外描述选位数为零。本题保证掩码在 1 至 7，课堂只在比较公式时推演零掩码。

下例由教师编写、严格 C11 编译并运行。两个函数分别接收各自的样本副本所在地址，用相同的位图连续查询。错误示范特意使用可写参数，使错误能够运行出来。

```c
int query_any(const struct Sample *sample, unsigned int mask)
{
    unsigned int selected = sample->flags & mask;
    return selected != 0u;
}

int query_any_wrong(struct Sample *sample, unsigned int mask)
{
    sample->flags &= mask;
    return sample->flags != 0u;
}
```

| 实际调用顺序 | 局部变量版 | 改写成员版 |
|---|---|---|
| 初始 flags = 13，第一次按 mask = 3 查询 | 返回 1，原值 13 | 返回 1，原值变成 1 |
| 分别对刚才那条记录按 mask = 8 查询 | 返回 1 | 返回 0 |

第一次返回相同，第二次才观察到 bit 3 丢失。学生能说明只读参数限制通过该参数改写成员；示例实现和第二次运行结果由教师展示。

## 实授补页｜接口里的位号和掩码

课堂位图从右边的 bit 0 起数。选 bit 1 时，位号为 1，掩码二进制低三位为 010，十进制值为 2。筛选可写 `count_flagged(samples, count, 1u << 1, MATCH_ANY)`；按位号更新可写 `sample_set_batch(samples, count, 1, 0)` 来关闭 bit 1。后缀 u 指无符号整数。严格 C11 中源码的 `010` 是八进制常量，数值为 8；标准 C11 没有 `0b010` 字面量。教师用静态断言严格编译验证 `2u == (1u << 1)` 和 `010 == 8`。学生就 `2u` 的含义和实际写法追问，独立构造新掩码留待复测。
