## 新知识 1：命令入口契约

### 03-code_codex/d15-command-entry.c

来源：D15 独立命令入口最终版，结构核心学生独立写，诊断拼写经提示修正；SHA-256：`1176A1E3011BAB58E62E7A4EFD84E35D578702AF48E25ACC8F7B750733951CEC`（教师实测版以此为准；空格待办见上，学习册保真收录当前字节）。

```c
#include <stdio.h>
#include <string.h>

int main(void){
    char text[16];
    const char *p = fgets(text,sizeof text,stdin);
    int N = 0 ;
    if (p == NULL)
    {
        return 0 ;
    }
    while (p != NULL)
    {
        char *nl = strchr(text, '\n');
        if (nl != NULL) {
            *nl = '\0';        /* '\n'在哪个地址，就把哪个位置改成'\0' */
        }if (strcmp(text,"RUN") == 0)
        {
            N ++ ;
            fputs("RUN_OK\n",stdout);
            p = fgets(text,sizeof text,stdin);
        }else if (strcmp(text,"STOP") == 0){
            N ++ ;
            fputs("STOP_OK\n",stdout);
            p = fgets(text,sizeof text,stdin);
        }else {
            N ++ ;
            fprintf (stderr,"line %d:BAD_COMMAND\n",N);
            p = fgets(text,sizeof text,stdin);
    }
    }
    return 0 ;
}
```
