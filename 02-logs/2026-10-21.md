## 卡点 / 疑问
- 中文标点混入代码（报错 stray '\342'），仍是最高频错误，手打代码时要全程切英文输入法
- 曾把 % 后面的字母当成变量名（写成 %a、%b）→ 已纠正：% 是「类型占位符」，按逗号顺序依次填进字符串里的占位符
- 整数除法陷阱：5/2=2，想要 2.5 必须写 5.0/2 或 5/2.0
- scanf 忘加 &（例外：%s 配字符数组不用加）
- 新遇到并解决的报错：
  - printf 字符串里没有 % 却多传参数 → 参数被静默丢弃（-Wformat-extra-args）
  - used uninitialized → 变量声明了没赋值就用
  - 只写 return 不写 0; → expected expression before '}' token
  - 程序没退出（没按 Ctrl+C）→ exe 被占用，重新编译报 Permission denied；此时直接 .\xxx.exe 跑的是旧程序，输出误导人 → 用 .\go 编译成功才运行，可避免

## 新学概念（一句话笔记）
- 变量 = 贴了标签的盒子：int / float / char 分别占 4 / 4 / 1 字节
- 引号内是纯文字、引号外才是变量；占位符按参数顺序填
- scanf 要往盒子里写东西，所以必须用 & 给出盒子的地址
- float 字面量要加 f 后缀（1.75f）；%.1f / %.2f 控制小数位数
- \n 是换行符，算一个字符
