## 新学概念（一句话笔记）
- if 是「先看条件，再决定做不做」；一排条件只会执行最先命中的那个 → 分档要先写严格的（大的在前）
- 判奇数用 `n % 2 != 0`，不用 `== 1`（负数如 `-7 % 2` 是 -1）
- if 条件里写 `=` 是赋值（几乎永远为真），比较必须 `==`
- if 的条件必须用括号括起来
