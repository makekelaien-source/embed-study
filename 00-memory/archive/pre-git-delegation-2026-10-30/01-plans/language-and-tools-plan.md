# Python、C++、Linux与工具学习计划

> 2026-10-27生效；正式必学任务，非仅看示例。L是学习周，日期由[排课台账](rolling-schedule.md)滚动维护。以下均为目标，尚无新通过记录。

## 课时与执行

Python63h、C++39h、Linux工具26h、Git/调试12h，共140h；L29–30另有10h语言补强。全部计入[总计划](overview-40week-plan.md)每周5h辅助预算；计算机基础3h另教OS/网络理论与实验，不重复计时。

先读[教学规范](teaching-guide.md)，每次先备讲义/验证短例，再由学生写目标核心。C为主固件语言，Python用于主机工具，C++用于独立PC日志工具；三个程序各有构建/运行方式。初验需学生代码、正常和异常测试、原因解释与提示记录，约一周后新变式复测；示范后仿写不记独立设计。

## 语言交付与验收

- Python：可独立启动的串口/日志/CSV/绘图工具，以及自动测试/故障注入入口；保留参数、超时、错误返回、依赖、样本及报告。无设备的回放不得冒充板端联调。
- C++：读取项目日志并统计数据的小工具，至少给出样本数/最大值/均值；空数据有明确策略，坏行记录或拒绝，缺文件可诊断；解释引用/const、类、构造析构、RAII及string/vector的使用与基本复杂度。允许先写文本/CSV版，不扩GUI或重写固件。
- Linux：PC核心与语言工具在干净目录构建/运行，记录Windows/Linux结果差异及依赖；进程/线程、同步、网络实验计入计算机基础课程。
- 指标和成果仅在真实运行后登记，课时是计划预算。语言任务未达标保留到补强/机动，不能只写“已阅读”或删除课程。
