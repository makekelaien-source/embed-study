## 一、switch —— "按楼层按钮"

### 1. 它解决什么问题

昨天写的 if-else if 链条, 是在问一连串**范围**问题: "temp >= 40 吗? 不是? 那 >= 30 吗?..."

但很多问题不是范围, 而是**一个变量等于某个具体值**:
- 输入 1~7, 判断是星期几
- 输入 1~12, 判断几月份

这种"一个值对一个值"的匹配, 用 if-else if 写又长又累, switch 就是专门为它准备的。

### 2. 类比: 电梯按钮

switch 像电梯: 你按 3 楼按钮, 电梯直接去 3 楼, 不会从 1 楼爬上去。
`case 3:` 就是"3 楼按钮", 变量的值等于几, 就直接跳到那个 case 后面执行。

### 3. 语法

```c
switch (变量) {
    case 值1:
        做的事;
        break;
    case 值2:
        做的事;
        break;
    default:
        以上都没匹配上时做的事;
}
```

逐个解释:
- `switch (day)`: 把 day 的值拿去和每个 case 比。
- `case 1:`: "如果 day 等于 1, 就从这里开始执行"。
- `break;`: **做完就离场**。没有它, 程序会"漏"到下一个 case 继续做 (见坑 1)。
- `default:`: 相当于 else, 所有 case 都没匹配上时走这里。可以没有, 但建议永远写。

### 4. 完整例子 (可直接运行)

```c
#include <stdio.h>

int main(void)
{
    int day = 0;
    printf("请输入 1~7: ");
    scanf("%d", &day);

    switch (day) {
        case 1:
            printf("星期一, 开工\n");
            break;
        case 2:
            printf("星期二\n");
            break;
        case 6:
            printf("星期六, 练习日\n");
            break;
        case 7:
            printf("星期日\n");
            break;
        default:
            printf("输入无效\n");
    }
    return 0;
}
```

输入 6 → 只打印 "星期六, 练习日"。输入 99 → 走 default。

### 5. switch 的三个规矩

1. switch 括号里只能放**一个整数类变量** (int 可以, float 不行, `day >= 3` 这种判断也不行)。
2. `case` 后面必须是**写死的常量** (case 1: 可以, case day: 不行)。
3. 每个 case 后面**几乎都要写 break**。

### 6. 坑

**坑 1: 忘写 break ("掉层")**

```c
switch (day) {
    case 1:
        printf("星期一\n");
    case 2:
        printf("星期二\n");
        break;
}
```

输入 1 会打印 "星期一" **和** "星期二" 两行! 因为 case 1 后面没有 break,
程序做完就顺势"掉"进 case 2 继续做。这是初学者 switch 第一大错。

**坑 2: case 后面写判断**

`case >= 3:` 是编译错误。范围判断请回用 if-else if。
经验: **查具体值用 switch, 查范围用 if**。

## 二、for 循环 —— "操场跑圈"

### 1. 它解决什么问题

"打印 1 到 100" 难道写 100 行 printf? "求 1+2+3+...+100" 写 100 个加号?
循环就是让程序**重复做同一件事**, 写一遍, 跑一百遍。

### 2. 类比: 操场跑圈

体育老师喊: "从第 1 圈开始跑, 只要没超过 5 圈就继续跑, 每跑完一圈圈数 +1"。

```c
for (i = 1; i <= 5; i = i + 1) {
    printf("跑完第 %d 圈\n", i);
}
```

for 括号里三段, 用分号隔开, 正好对应老师那句话:

| 段 | 代码 | 什么时候执行 | 大白话 |
|----|------|-------------|--------|
| 第 1 段 | `i = 1` | 只开始时报一次数 | 从第 1 圈开始 |
| 第 2 段 | `i <= 5` | 每一圈开始前检查 | 没超过 5 圈吗? 超过就散会 |
| 第 3 段 | `i = i + 1` | 每一圈结束后 | 圈数 +1, 再来一圈 |

执行顺序: 报起点 → 检查 → 跑身体里的活 → +1 → 再检查 → ... → 检查失败就结束。

### 3. 完整例子: 求 1+2+...+100 (可直接运行)

```c
#include <stdio.h>

int main(void)
{
    int i = 0;
    int sum = 0;

    for (i = 1; i <= 100; i = i + 1) {
        sum = sum + i;
    }
    printf("1+2+...+100 = %d\n", sum);
    return 0;
}
```

- `sum` 像一个存钱罐, 先清零, 每圈把 i 投进去。
- 循环结束时 sum = 5050 (高斯小时候算的就是这个)。

### 4. 循环 + if 合体

循环负责"挨个过一遍", if 负责"挑出符合条件的":

```c
for (i = 1; i <= 20; i = i + 1) {
    if (i % 7 == 0) {
        printf("%d 是 7 的倍数\n", i);
    }
}
```

1~20 里会打印 7 和 14。`i % 7 == 0` 读作 "i 除以 7 余数为 0", 即整除。

### 5. 坑

**坑 1: for 后面多写一个分号**

```c
for (i = 1; i <= 100; i = i + 1);   /* <- 这个分号是灾难 */
{
    sum = sum + i;
}
```

分号 = "这一轮什么都不做"。程序会空转 100 圈, 大括号里的活只做了 1 次。
**for ( ... ) 后面永远直接跟 { , 不跟分号。**

**坑 2: 边界差一个 (off-by-one)**

`i <= 100` 会跑到 100, `i < 100` 只跑到 99。写完循环先问自己:
"最后一次 i 是几?" 想清楚再选 <= 还是 <。

**坑 3: 循环变量忘了先声明**

`int i = 0;` 要在 for 之前写好 (我们目前用的 C 标准不允许写在 for 括号里)。

**坑 4: `x = x++;` 是空操作 (2026-10-24 d4-ex4 实际踩到)**

```c
hot = hot ++;   /* 错! 绕一圈等于什么都没改 */
```

`hot++` 的意思是"先把旧值交出去, 然后自己加 1"。执行顺序:

1. 把 hot 的旧值 (比如 0) 交出来
2. hot 变成 1
3. 但第 1 步交出来的旧值 0, 又被 `=` 赋值回 hot -> hot 打回 0

计数器永远卡在 0, 程序不报错, 只是数字不动 — 这种 bug 最难发现。

正确写法 (三选一, 效果完全一样):

```c
hot = hot + 1;
hot += 1;
hot++;          /* 单独一行用, 不要和 = 搭配 */
```

记忆口诀: **`++` 单独用, 不要写 `x = x++`。**
