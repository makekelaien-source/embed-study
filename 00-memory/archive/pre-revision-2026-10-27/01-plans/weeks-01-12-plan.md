# 第 1–12 周逐周计划（阶段0 + 阶段1 开头）

> 全职基准 40h/周。每周末对照「检验标准」自评，未达标就用周日缓冲补，连续 2 周不达标就调整计划。
> Python 辅助线从 W3 起每周 2~3h（见总览「Python 辅助线」）；当周 C 任务未完成，Python 时段取消。
> 周 = 周三至下周二（W1: 10/21–10/27，依次顺延）。

## W1（10/21–10/27）C 起步 + 环境搭建
- 编程：装 VS Code + MinGW(gcc) + Code Runner；变量、数据类型、运算符、printf/scanf、编译运行流程
- 硬件：Arduino Uno 起步包下单；理解电压/电流/电阻的水流类比
- 练习：Hello World、摄氏转华氏、三角形面积，共 10 个小程序
- ✅ 检验：命令行 `gcc xx.c -o xx` 独立编译运行；能说清 int/float/char 占几个字节

## W2（10/28–11/03）控制流
- 编程：if/else、switch、for/while/do-while、break/continue；嵌套循环
- 练习：九九乘法表、判断素数、猜数字游戏（控制台）、Fibonacci
- 电子：串联/并联、欧姆定律计算（LED 限流电阻：(5-2)/20mA=150Ω）
- ✅ 检验：不看书写出素数判断与打印 1–100 全部素数

## W3（11/04–11/10）函数与数组
- 编程：函数定义/参数/返回值、作用域、数组（一维/二维）、字符数组与字符串
- 练习：写 max/排序(冒泡)/数组求平均；杨辉三角
- 电子：分压电路计算与面包板实测（万用表）
- Python(2h)：变量/类型/print/input，对照 C 的差别（不用分号、缩进即代码块）；把摄氏转华氏重写成 Python
- ✅ 检验：独立实现冒泡排序并解释每行作用

## W4（11/11–11/17）指针 I（第一道坎，多花时间）
- 编程：地址概念、指针定义、指针与数组、指针运算、`&`/`*`
- 练习：用指针遍历数组、指针交换两数；画图表示内存
- 电子：二进制/十六进制转换，手算 0x3F & 0x18 等
- Python(2h)：if/for/while 对照 C 写法；把九九乘法表、素数判断重写成 Python
- ✅ 检验：LeetCode 简单题累计 15 道；能画出 a[3] 与 *p++ 的内存图

## W5（11/18–11/24）指针 II + 字符串
- 编程：指针作函数参数（"传址修改"）、二级指针、const 指针、字符串函数(strcpy/strlen 手写)
- 练习：手写 strlen/strcpy/strrev；函数内修改主调变量
- Python(2h)：函数/列表/字典；把冒泡排序重写成 Python（感受内置 sort 与切片）
- ✅ 检验：不查库实现 strcpy 并解释；说清为什么 C 函数能改外部变量、什么时候要传指针

## W6（11/25–12/01）结构体与链表
- 编程：struct、结构体数组/指针、typedef、enum、点与箭头
- 练习：学生成绩管理（结构体+数组版）；单链表：增删打印
- Python(2h)：文件读写 + 字典综合；把学生成绩管理重写成 Python（dict + 存文件）
- ✅ 检验：独立从零写单链表（malloc 版）并能画出节点图

## W7（12/02–12/08）位操作 + 动态内存（嵌入式核心技能）
- 编程：& | ^ ~ << >>、置位/清零/翻转宏；malloc/free、内存泄漏概念
- 练习：写 `SET_BIT(REG,n)` 类宏；用位操作模拟"寄存器"控制假 LED 状态
- Python(2h)：用 Python 做 3~5 道 LeetCode 简单题（字符串/数组），体会内置函数效率
- ✅ 检验：LeetCode 累计 30 道；说出 `(1<<n)` 在寄存器配置里的含义

## W8（12/09–12/15）预处理与多文件工程
- 编程：#define/宏函数、头文件、#ifndef 保护、多文件编译、简单 Makefile
- 练习：把 W6 学生管理拆成 .h/.c + Makefile；队列(数组环形)实现
- Python(2h)：import 与 #include 的差别、模块与 pip；写一个小工具脚本（批量重命名/统计代码行数）
- ✅ 检验：LeetCode 累计 50 道；多文件工程 `make` 一键编译通过

## W9（12/16–12/22）电子集中 + Arduino 上手
- 电子：数字电路基础（高低电平、逻辑门）、上拉/下拉电阻、按键抖动概念；万用表测通断/电压
- 硬件：Arduino：点灯、按键、millis 非阻塞、串口打印、I2C OLED 显示
- 工程：03-代码 建 Git 仓库，每日提交
- Python(3h)：pyserial 入门——用 Python 读写 Arduino 串口（发指令点灯 / 收传感器值）
- ✅ 检验：Arduino 按键控制 LED 模式切换（不用 delay 阻塞）

## W10（12/23–12/29）阶段0 收官项目
- 项目：Arduino 温湿度(DHT11) + OLED + 串口输出，阈值报警
- 复盘：C 语言查漏补缺（错题本过一遍）
- Python(3h)：pyserial 读 DHT11 串口数据存 CSV + matplotlib 画曲线（给收官项目加"上位机"）
- ✅ 检验（阶段0 里程碑）：LeetCode 50 道；从零写链表+队列；Arduino 项目演示成功；万用表使用熟练

## W11（12/30–01/05）STM32 入门
- 环境：STM32F103C8T6 + ST-Link + STM32CubeIDE；CubeMX 生成工程流程
- 内容：GPIO 输出、点灯（寄存器版 vs 库函数版对照）、读数据手册引脚表
- Python：暂停（STM32 是新坎，全部时间让给 C/硬件）
- ✅ 检验：CubeMX→生成→编译→烧录全流程独立走通

## W12（01/06–01/12）按键与中断
- 内容：EXTI 外部中断、按键消抖（硬件 vs 软件）、中断概念（对比 Arduino attachInterrupt）
- 工具：逻辑分析仪（若已购）看按键电平抖动波形
- Python(1h)：保温：用 Python 做 1~2 道 LeetCode 简单题
- ✅ 检验：中断控制 LED 翻转 + 主循环做别的事互不阻塞；能讲"中断"是什么
