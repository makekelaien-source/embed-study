## Python 辅助线（就业加分项，2026-10-21 加入）
> 就业相关度判断：嵌入式岗 JD 高频写「会 Python 脚本/上位机工具/测试自动化优先」→ 要学；
> Web 后端、爬虫、深度学习等与嵌入式无关 → 不学。
> 深度目标：**能写工具脚本、能读懂测试代码**，不搞 Python 深水区。
- 阶段0（W3–W8）：语法基础，每周 2~3h，对照 C 学（已装 Python 3.12）；里程碑：把 5 个 C 小程序重写成 Python
- 阶段1（W9–W22）：pyserial 上位机 + 数据处理；里程碑：自制串口采集工具（存 CSV + matplotlib 画图）
- 阶段2（W23–W30）：pytest 基础、烧录/测试流程自动化；里程碑：给自己的 FreeRTOS 项目写自动化测试脚本
- 阶段3（W31–W38）：给项目③写 MQTT 上位机监控页 / OTA 测试脚本
- 求职（阶段4）：简历技能栏写「Python：上位机工具、测试脚本、数据分析」
- 铁律：Python 不挤占 C 主线时间，当周 C 任务未完成则当周 Python 时段自动取消

## 贯穿项（每周都做）
- 每日日志（02-日志），写「今天做了什么/卡在哪」
- 笔记沉淀到 04-笔记（错题本式：概念一句话 + 代码片段）
- 代码全部进 03-代码 并用 Git 管理（W9 起强制）

## 八股范围（阶段2 起每周抽 2h 过一遍）
C 指针/内存管理/volatile/static/const；中断流程与注意事项；RTOS 调度、优先级反转、看门狗；
I2C/SPI/UART 时序与区别；上拉下拉、去耦电容、三极管/MOS 开关电路。
