> 生效：2026-10-27，替代旧全职 40h/周版。W1=2026-10-28–11-03，之后每周三至下周二。Day 为实际学习日编号，不等于日历天或周次。

## 目标和投入

- 张博宣，东南大学建筑学硕士在读，预计 2029 年暑期毕业；希望 2027 年 9 月以后开始实习。
- 每周 20–25h，以 22h 为基准：讲解/复习/基础练习 6h，独立编程/项目 9h，算法 2h＋计算机基础 2h，测试/文档/复盘 3h。Python、Linux、C++占对应阶段既有时段，不额外加预算。
- 主线 C → STM32 裸机 → FreeRTOS → 工程验证；Python 服务测试，Linux 服务开发与系统基础，后半程补 C++ 阅读能力。
- 2027 年 6–7 月形成展示和面试能力，8 月投递及缓冲；提前关注岗位，按当时届别、到岗和持续实习要求筛选，不能假定 2029 届符合某 2027 实习项目。
- 提高难度依靠独立排错、边界测试、测量、迁移和设计解释。取消刷题数、代码行数或学习日数过关标准。

## 贯穿训练

- 算法：数组/字符串 → 链表、栈/队列、查找排序和复杂度。每周一个独立小题和一个旧题变式，按用时缩减数量；链表训练指针，不强用于采集缓冲区。
- 计算机基础：数制/位宽 → 内存布局/编译链接 → 栈堆/生命周期 → 中断并发 → 操作系统/网络；每周联系代码解释一个问题。
- Python：文件、测试语法 → 串口配置、CSV、绘图、故障注入和汇总。C 卡住时压缩新 Python 内容，已依赖的测试工具继续使用；不再大量重复改写入门题。
- Git：W1 开始本地教学，提交可解释的改动；掌握差异、恢复指定文件、实验分支。远程发布前检查隐私和第三方授权；本次计划实施不代替学生 Git 初练。
- 英文阅读：每周一个官方小节，找参数、限制和依据，占讲解复习时段。
- C++：W31–36 补引用/const、类、构造析构、RAII、容器和基本复杂度；不替换 MCU C 项目。

## 平台与边界

默认 NUCLEO-F446RE、STM32CubeIDE、C、HAL、FreeRTOS。板载 ST-LINK，先学 HAL 和工具链，再选 GPIO/定时器对照寄存器。Cube 生成与手写代码分开，说明构建及启动流程。

W3 核对器材并开始低压实操；争取最迟 2026-11-27 前完成上电、烧录、断点、点灯和串口观察。器材未就绪则推进 PC 模块及回放测试，硬件成果仍标未测。旧预算 500–700 元只作参考，核对已有、待购及当时价格后由学生下单，不默认再买 Arduino/ESP32或独立 ST-LINK。

核心不包含 Wi-Fi、MQTT、OTA、手机 App、自制 PCB、指定低功耗电流指标及高功率线圈闭环。它们只在核心过关且学生重新选择后另立扩展。建筑与磁场课题可作背景，不能挤占固件基础。

## 进度与缓冲

- 每周六个可移动学习单元、一天休息；22h 可分五次 3.5h＋一次 4.5h，穿插休息，实际时长如实记。
- 每周末检查核心、提示、延期和前置；W4/8/12/16/20/24/28/32/36/40 阶段评估包含在周预算。
- 核心连续两次失败，同周拆题补基础、减新功能。复测通常完成后 7±2 天，不为赶周次跳过。
- 课题/春节/考试冲突时调整周内任务；欠账超过一周先重新估时、删选做，用 W41–44 补核心；窗口改变则修订排期留记录。
- 旧 Day 0–7 是学习经历，从诊断恢复能力证据，不全盘重学。
