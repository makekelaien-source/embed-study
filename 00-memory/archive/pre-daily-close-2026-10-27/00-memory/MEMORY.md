## 准确知识与待补强

- C调用前需要正确可见的声明，定义可在后；不再写“必须定义在调用前”。
- C中 x = x++ 是未定义行为，不能视为空操作；副作用拆开。
- C是值传递，指针值也被复制；通过所指对象修改与“传值”不矛盾。
- void允许无可观察副作用，也可return;；不能说必须打印或改外界。
- 作用域、生命周期、存储期分开，static局部不随离开块而销毁；普通非void函数应覆盖正常返回路径，main有末尾返回的特殊规则。
- 局部历史例题的成功不推断广泛掌握；后续按能力表升级。
- 历史课堂曾容许阈值或风格问题不改；项目中业务阈值、边界与安全状态属于需求，必须验收。
