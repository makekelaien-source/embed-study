# D19｜课堂补页：从样本标志位到独立快照

配合 D19 学习册所收课堂日志、两份讲义及各版原码阅读。本页汇总实授扩展，例子与测试分开标识。

## 位号、对象和断点

三盏灯由最低三位表示，查询 bit 2 可构造掩码 `1u << 2`。低三位为 101 时，按位与结果为 100；没有赋值写回，原来的 101 保留。学生独立答对这一点。

结构体 `saved = current` 复制整型温度成员 24。指针 `p` 指向 current，调试器停在 `p->temperature = 31` 所在行时，两对象温度均为 24，执行 next 后分别是 31、24。学生正确解释停在行上和执行完该行的区别。

在两条传感器记录中区分下标和位宽：编号 2、256；正确读取第二条得到 256，固定读第一条得到 2，先把第二个编号存入 uint8_t 再取出得到 0。教师给过 256 的边界提示，学生选择第一条为 2，并把第三个输出由 1 更正为 0。

## FIFO、回绕与有效范围

容量 3 时 head 是下一读位置，tail 是下一写位置，count 属于 0 到 3。读满一圈或写满一圈，下标从 2 回到 0。槽里残留的 0、负数或上次的旧值都不能表示队空。给定 head 和 count，从 head 开始数 count 项才得到待处理序列。

| 操作 | head | tail | count | 待处理顺序或输出 |
|---|---:|---:|---:|---|
| 空队列入 10、20 | 0 | 2 | 2 | 10、20 |
| 出队 | 1 | 2 | 1 | 输出 10，剩 20，槽 0 仍可留 10 |
| 入 30 | 1 | 0 | 2 | 20、30 |
| 入 40 | 1 | 1 | 3 | 20、30、40，槽数组为 40、20、30 |
| 尝试入 50 | 1 | 1 | 3 | QUEUE_FULL，原顺序全部保留 |

C 可以写入合法下标，FIFO 仍须在满队列拒绝写入，否则最早的未处理项被覆盖。出队通过 `*out = q->slots[q->head]` 把整数复制给调用者，head 前移，count 减一；空队列返回 QUEUE_EMPTY 并保持 out。成功返回 QUEUE_OK；判定成功依据状态，因为合法数据也可以等于输出变量原值。队首和队尾下标相等可以表示空，也可以表示满，区别在 count。

入队旧稿遗漏 tail/count，后续写覆盖槽 0；另一稿错误推进 head，跳过最早项。出队旧稿把容量当实际数量、把整数赋给指针，并误将出队计数递增。教师 GDB 在旧稿第 21 行观察满队列取 10，执行前 count 为 3、out 为 10；next 后 count 为 4，正确值为 2。学生定位断点并描述增减方向。批量验收和调试器执行归教师，详细结果见课堂记录。

## 比较两个队列

数组 A 为 [10,20,0]、head 为 0、count 为 2；数组 B 为 [99,10,20]、head 为 1、count 为 2。两者逻辑序列同为 10、20。出队读出数值后旧槽保留。若两个数组同为 [10,20,30] 且 count 均为 2，head 分别为 0 和 2，则读到 10、20 和 30、10。

只读比较应先核对两队列元素数量，再从各自 head 对应读取。首次不等可返回 0；有效元素全部配对则返回 1。旧稿把递减后的本地计数与原队列计数混用，相同单元素 10 比完之后又比较旧槽 70、80，误报 0。修订稿教师验证 9,216 组双队列组合并检查输入保持。比较最坏为 O(n)，额外空间 O(1)，两份同步递减的计数可精简。教师实测断在最终稿第 29 行时，逻辑第 2 对的物理槽号分别 1、0，值分别是 20、30。

队列原有 100 项时，左移出队要复制 99 个剩余元素；环形实现不搬剩余元素，只更新下标和计数。学生正确预测两者的搬移数。

## 申请、释放和复制

- 在本题限定的 1 到 8 个 int 范围内，`malloc(capacity * sizeof *slots)` 请求所需字节。成功得到地址，未写过的槽不保证为 0。失败得到 NULL。动态初始化另约定容量 0 时不申请。所有权由初始化成功的队列持有。
- `int saved = slots[0]` 复制整数；`int *view = slots` 复制地址。通过 view 改槽值能从 slots 观察到。单独给 view 赋 NULL 只改变该指针变量；单独 free 原地址则结束同一块分配的使用。调用者用 `&value` 作为输出位置时，`*out = slots[0]` 把整数交给 value，释放原槽后 value 仍可读取。
- 释放次序是保留有效地址至 free 调用，再将成员置 NULL。先置 NULL 会丢失唯一地址；free(NULL) 安全返回。销毁函数同时重置 capacity、head、tail、count，支持再次销毁及重新初始化。一次有效分配只释放一次。
- `struct DynamicQueue b = a` 复制各成员。两个 count 各自独立，两个 slots 指针共享同一块分配。释放 a 后 b 的成员未被赋值，但共享的槽位已释放，不可再经 b 访问或释放。教师对照学生最终能复述悬空指针与空指针的区别，独立迁移待复测。
- 深拷贝先为目标队列申请独立槽位，把源队列的 count 个有效整数按逻辑顺序复制到目标槽 0 起。源为 [20,99,10]、head 为 2、count 为 2 时，目标应存 10、20。复制失败返回 0 且无有效快照；成功返回 1，修改或销毁原队列后仍能读快照。
- 传参先看表达式类型。结构体变量 q 要传给队列指针形参时写 &q；dst 本已是队列指针，直接传 dst。容量成员传给 size_t 形参时用数值 src->capacity。数组名在函数实参中通常转换成首元素指针，&slots[i] 是某一元素的地址。p+i 按 i 个元素偏移，p 自身不变；p+=i 将位置写回 p。数组尾后一位可以作为遍历终点，不能解引用或自行绕回首槽。
