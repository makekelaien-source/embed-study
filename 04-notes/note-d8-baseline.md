## 2. 预测A：返回值与原变量

先写下两行输出和原因，再编译运行核对；不要先运行后填写预测。

```c
#include <stdio.h>

int bump(int x)
{
    x = x + 1;
    return x;
}

int main(void)
{
    int v = 3;
    bump(v);
    printf("%d\n", v);
    v = bump(v);
    printf("%d\n", v);
    return 0;
}
```

追问：参数x和main里的v是否同一个对象？第二次调用后的结果是怎样进入v的？类比边界：复印件只能说明参数值复制，等学指针后还要区分复制地址与共享对象。

## 3. 预测B：return是否只跳出循环

先画执行顺序，再写输出和原因。

```c
#include <stdio.h>

int sample(void)
{
    int count = 0;
    while (count < 3)
    {
        count++;
        if (count == 1)
        {
            return count;
        }
    }
    return count;
}

int main(void)
{
    printf("%d\n", sample());
    return 0;
}
```

追问：如果希望完成三轮再返回，该把“返回结果”职责放在哪一阶段？此处只讨论已教流程，不引入指针或RTOS。

## 5. 缺口补讲（只在前面需要时使用）

- 函数像一个输入/处理/输出接口：比较函数仅接收猜测和目标、返回-1/0/1，不负责scanf和累计次数；主循环组织交互。类比不意味着所有函数必须有参数或返回值。
- 普通函数写在文件作用域，调用前有正确声明即可；先定义再调用是当前简便方式，随后讲原型，不能说定义必须在前。
- 返回值与副作用分开；void不返回值，也允许没有打印。用一两个最小示例带读后再给相关变式。
- 先解释编译诊断，再逐步采用C11/Wall/Wextra/Wpedantic；不要为了消除警告屏蔽选项。
