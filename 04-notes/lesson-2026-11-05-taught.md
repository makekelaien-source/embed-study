## 从标准输入读到字符数组

```c
#include <stdio.h>
int main(void)
{
    char text[8];
    if (fgets(text, sizeof text, stdin) == NULL) {
        puts("READ_FAILED");
        return 0;
    }
    printf("TEXT=[%s]\n", text);
    return 0;
}
```

`text` 是目标数组，`sizeof text` 是该对象的字节容量，`stdin` 是读取来源。终端键入提供字符，fgets 取走字符并存入数组，printf 才负责显示。没有可用字符且终端未结束时，读取通常等待新输入；输入文件确实结束时不会等待。程序可以先 printf 提示（无换行时可 fflush(stdout) 确保及时显示），读写各有职责。

容量8最多取7个输入字符，最后写一个空字符。容量足够时读到换行会保存换行然后停止。实际按空格产生 `' '`，按回车提供 `\n`，`\0` 由读取函数补上。输入 `A B` 回车时下标0至4依次是 `'A'`、`' '`、`'B'`、`'\n'`、`'\0'`；5至7未被本次写入。`%s` 显示到第一个结束符为止，换行会让右括号出现在下一行。成功返回目标首地址，读取失败返回 NULL，调用方先检查再使用数组。`sizeof(data) / sizeof(data[0])` 适用于真实数组，不能在指针形参上恢复调用者容量。`(sizeof) data` 语法错误。

scanf 按格式取得或转换数据；`%d` 直接转换整数，`%s` 跳过前导空白并在后续空白处停止。fgets 保留读到的空格和换行，按文本交给调用者。宽度 `%7s` 是最多读7个输入字符，另补结束符；fgets 的参数8是总空间。不限宽 `%s` 把8字母和结束符写进8格会越界，外层循环不能修复第一次越界。已教对照 `while (scanf("%7s", data) == 1) { printf("%s", data); }` 可分段显示无空白文本；scanf返回成功转换项数，fgets返回指针。分段读取也可 `while (fgets(data, sizeof data, stdin) != NULL) { printf("%s", data); }`，逐段处理，数组下次会被改写，需全部保存在内存时另设计空间。

## 一次读取与整行状态

容量8的对照：6字母+回车 → 数组容纳6字母、换行和结束符；7字母+回车 → 数组容纳7字母和结束符，换行留在流里；8字母+回车 → 前7字母进入数组，第8个字母和换行留在流里。教师原题“装满7个字符”表述有歧义，精确要求是“取走7个输入字符，第8格放结束符，换行留在输入流中”。

`read_text(dest, capacity)` 契约：容量不足2返回-1且不读不写；fgets失败返回0；读到换行将该位置写成结束符并返回1；成功未见换行返回2。返回2只报告此次未见换行，可能正文恰满、有额外正文、或末尾无换行。调用者只在有效状态使用文本。函数一次返回一个int；写入dest是另一条交付途径。

首稿 `else return 2` 放在循环内，首字符非换行时提前结束。第二稿扫到容量才结束，越过首结束符；教师先初始化数组旧尾部换行，输入文件ABC无换行，稳定重现误返回1。把换行与结束符合并为同一return1仍错，两种停止原因应分开。else if必须在for内接if，循环的i离开作用域不可用；循环后默认返回覆盖普通非void路径。学生修正后教师12例过，随后学生主动补main接status并保护打印，原程序五例过。

多次读取都从同一个stdin继续。两个数组决定写入位置，a/b只是接状态。7字母回车后再提供第二行Z，第二次read_text先消费前一行残留换行并得到空串和状态1，Z留在流中；若首读已消费换行，额外读取会取得下一行字符或等待新输入。既不能把读取次数直接当行数，也不能把数组内容当作输入流的剩余内容。

## 读下一字符与行尾恢复

`int ch = fgetc(stdin);` 从当前输入流位置取一个字符。用int保留字符值和EOF这个特殊返回。成功时不补字符串结束符。先由read_text取走前7字母，fgetc从剩余位置继续。只在状态2时检查，防止额外消费下一行。

```c
int ch = fgetc(stdin);
while (ch != '\n' && ch != EOF) {
    ch = fgetc(stdin);
}
```

条件检查已经读到的ch，循环体才取下一字符。H → I → 换行的路径中，判断I时可以执行下一次fgetc并取走换行，然后在新一轮判断停。首取已经是换行时循环体零次，学生对照后答对。`!= '\n' || != EOF`在两个停止点总有一项为真，超长行会卡住。学生`check_tail`先分首取换行1、首取EOF0、首取普通字符再清至换行或EOF后返回2；H2把||改&&后教师五例过。H/I已出现后再遇EOF只让循环停，不重新进入首取EOF分支，学生独立解释正确。真正的读取错误与EOF结束下一课再区分。

## 声明、定义与链接
