## 本次新增目标

字典dict将字段名（键）与数据（值）成对保存，用键读取/修改一条测量记录，区别列表位置下标。当前一次只讲字面量与键读取，后续再讲更新和缺失键；模块/import和路径不提前混入这一单元。

## 直观示例与准确术语

一条温度测量有当前温度temperature和阈值limit，可写sample={"temperature":26,"limit":30}。{}建立字典，每对由key:value组成，逗号分隔。键是字段名字符串，值是对应数据；sample["temperature"]按键取值，与列表位置编号不同。此例字符串键和整数值，不泛化键的所有类型限制。

```python
sample = {"temperature": 26, "limit": 30}
print(sample["temperature"])
print(sample["limit"])
```

先预测两行输出再运行。无函数依赖，完整可运行，不要求复制旧函数。
