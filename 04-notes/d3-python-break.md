# D3追加单元：while True与break

学生明确继续学习后安排，延续L1 Python循环，不回切语言。前置：while条件、循环内更新输入、if、整数输入，C中最近循环的break已解释正确；本次目标是在Python中使用显式退出。

## 新知识与最小例子

True是布尔真值，大小写固定。while True每轮条件都为真，本例用break作为正常退出路径。break立即退出最近一层循环，循环后语句继续执行。

```python
while True:
    number = int(input("整数："))
    if number == 0:
        break
    print(number)
print("结束")
```

先读取，再判断停止，非停止才处理。输入只在循环内一处，仍每轮读取。停止标记判断应在业务统计之前。

教师实际Python两例验证：7/0/9仅回显7再结束，读取提示2次；首项0直接结束，提示1次；均退出0无stderr。这是教师证据，不算学生通过。

## 理解检查

学生预测依次提供7/0/9时输出哪些数、9会不会被读取。先答后安排代码，不提前给整题目标实现。
