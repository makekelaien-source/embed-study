# Day 6 讲义：素数判断（W2 检验项的核心）

日期：2026-10-26

## 一、什么是素数（概念类比）

素数 = 只能被 1 和自己整除的整数（2, 3, 5, 7, 11 ...）。

类比：你有 num 颗糖，想每 i 颗装一袋、正好装完不留剩。
- 如果某种装法（i = 2, 3, 4 ...）正好装完（也就是 num % i == 0），说明 num 有"别的因数"，它**不是**素数。
- 把 i 从 2 一路试到 num-1，**全都装不完**（都有剩），它才是素数。

所以判断素数 = 把每种装法都试一遍，一种"正好装完"的都找不到，才算数。

## 二、你昨天错在哪

你昨天的写法：i 刚等于 2 就下结论——
- 9 % 2 == 1（除不尽）→ 你直接说"是素数"。错！9 = 3*3，要试到 i=3 才发现。
- 一次除不尽不算数，**全部**除不尽才算数。

## 三、正确套路：旗子变量（flag）

先假设它是素数，立一面旗子 is_prime = 1（1 代表"是"）。
循环里一旦发现 num % i == 0，就把旗子放倒 is_prime = 0，并 break（不用再试了）。
循环结束后，只看旗子：旗子还立着 → 是素数。

```c
#include <stdio.h>
int main(void)
{
    int num = 9;
    int i;
    int is_prime = 1;          /* 先假设是素数, 旗子立着 */

    for (i = 2; i < num; i++)  /* 试 i = 2, 3, ... num-1 */
    {
        if (num % i == 0)      /* 发现能整除! */
        {
            is_prime = 0;      /* 旗子放倒 */
            break;             /* 已经定性, 不用再试 */
        }
    }

    if (num <= 1)              /* 0 和 1 特殊, 不是素数 */
    {
        is_prime = 0;
    }

    if (is_prime == 1)
    {
        printf("%d 是素数\n", num);
    }
    else
    {
        printf("%d 不是素数\n", num);
    }
    return 0;
}
```

跑这个例子：9 → 9%2=1, 9%3=0 → 旗子放倒 → "9 不是素数"。正确。

关键点逐条：
1. `is_prime = 1` 开头先假设成立，后面只负责"推翻"。
2. 循环条件 `i < num`（试到 num-1 就够，不用 `i <= num`）。
3. 循环里**只做一件事**：发现能整除就放旗子 + break。发现除不尽**什么都别做**，继续试下一个 i。
4. 判断"是/不是"放在**循环外面**，只看旗子。

## 四、100 以内所有素数 = 上面的套路套一层循环（嵌套）

外层 n 从 2 数到 100，每个 n 都走一遍上面的判断：

```c
#include <stdio.h>
int main(void)
{
    int n, i, is_prime;
    for (n = 2; n <= 100; n++)
    {
        is_prime = 1;              /* 每个新 n 都要重新立旗子! */
        for (i = 2; i < n; i++)
        {
            if (n % i == 0)
            {
                is_prime = 0;
                break;
            }
        }
        if (is_prime == 1)
        {
            printf("%d ", n);
        }
    }
    printf("\n");
    return 0;
}
```

答案应有 25 个，第一个是 2（2 没有任何 i 能整除它，旗子一直立着）。
