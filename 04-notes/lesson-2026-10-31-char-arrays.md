# L2-4：字符数组与字符串结束标记

## 目标与前置

前置：数组、下标、sizeof、指针/数组区别。新知识先分两点：char与字符数组；C字符串以空字符\0结束。随后才讲容量与受限输入，不提前考字符串库函数。

## 最小示例

```c
char letter = 'C';
char tag[] = "CAT";
```

单引号'C'是字符常量，可用于初始化char；双引号"CAT"是字符串字面量，这里初始化一个独立字符数组。tag有4个元素：'C'、'A'、'T'、'\0'。数组长度包含结尾的空字符，sizeof(tag)为4字节（sizeof(char)恒为1个C字节）。\0的值为0，与字符'0'不同。不要把它称为NULL指针。

等价数组初始化：

```c
char tag[] = {'C', 'A', 'T', '\0'};
```

读取单字符用printf的%c，读取合法以\0结尾的字符序列用%s。%s通过传入地址访问字符直到空字符；不向未终止数组使用%s，不演示不确定输出作为结果。

```c
printf("%c\n", tag[0]);
printf("%s\n", tag);
```

可见文本CAT长度3，存储数组容量4；结束符占空间但不作为可见字母输出。容量可以大于所存文本长度，后续再教安全输入宽度与预留终止符。
