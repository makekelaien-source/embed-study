## 主任务：猜数字游戏 `03-code\d6-guess.c`

分 5 块写，每块写完编译一次：

1. 难度选择（switch）
   - 菜单：1 简单 / 2 中等 / 3 困难
   - case 1: 答案 42，范围 1~50
   - case 2: 答案 77，范围 1~100
   - case 3: 答案 385，范围 1~1000
   - 答案写死，不用 rand
2. 猜的主循环（while(1)）
   - scanf 读 int 猜测值
   - if/else 三分支：猜大了 / 猜小了 / 猜对了（对了 break）
3. 计次：int cnt = 0，每猜一次 cnt++（不要写在 break 之后）
4. 评级（if / else if）：<=5 大神、<=10 不错、否则有点慢
5. 再来一局（do-while）：整局包进 do { } while (again == 1);
   - 局末菜单「1 再来一局, 0 退出」，scanf 读 int 存进 again
   - 用 int 不用 char，避免 scanf 吃换行

自查清单（都是踩过的坑）：
- scanf 加 &
- if 里 == 不是 =
- while 后不加分号
- switch 每个 case 加 break
