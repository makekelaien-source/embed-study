## 一、指针参数仍是值传递

对象是存储数值的具体变量；指针变量保存地址。&result取对象地址，*output访问该地址对应对象。函数形参可以与调用者变量不同名。传指针时复制的是地址值，修改所指对象可以影响调用者；改变形参自己的值不是修改调用者的普通整数变量。

```c
void set_value(int *output) { *output = 12; }
int main(void) { int result = 4; set_value(&result); return 0; }
```

学生H0预测result12及理由正确。普通局部int index;没有确定初值，read_at(word,index,&selected)在进入函数前就需要读取index。函数内再index=2不能修复此前读取，也不能修改main里同名index。若传入1后函数再把形参赋2，后续text[index]读取下标2，学生曾预测1，按执行顺序补讲。

## 二、数组名、元素值、元素地址

在普通调用表达式中，数组名text转换为首元素地址；text[i]是一个char值；&text[i]和text+i是第i个元素的地址。函数参数char *text和char text[]在这里都接收指针；p[i]等价*(p+i)，指针也能用下标访问。不能从“传数组名无需&”推成“任何表达式都不加&”。

read_at只读text[index]并通过*output写回字符；截断由main决定。单个char打印%c，字符串打印%s。char值作为可变参数会提升为int，不能把它传给需要char*的%s。学生最终短迁移三个下标及源数组不变断言通过，但经明确提示完成。

## 三、容量与字符串长度

```c
char text[8] = "OK";
```

容量8；初始布局O、K、结束符以及其余零初始化元素，文本长度2。把text[1]改为空字符后长度1、容量仍8。char source[]="HELLO"由初始化推算容量6，含结束符，创建后不再随输入改变。不是char source[]声明后等scanf决定容量。

```c
char type[999];
if (scanf("%998s", type) != 1) { return 1; }
```

%s最多读入998个非空白字符，再补结束符；数组仍有999格，输入cat写入c/a/t/结束符，长度3。剩余未初始化格不能假定为0；与带字符串初始化时剩余元素零初始化不同。宽度是读入上限，不表示整个输入行都已验证。输入空格会终止%s。

sizeof对真实数组测整数组字节，除单元素大小得容量；函数内source是指针，sizeof(source)/sizeof(*source)测指针大小/char大小，不是容量，更不是文本长度。sizeof不会向后寻找空字符。当前text_length通过逐个检查直到首个结束符求长度；循环不能固定100，不能每轮break；空串应返回0。

字符数字'0'不同于结束符'\0'。输入A0B的布局是A、数字0、B、结束符；长度3。若判断数字0，会在下标1错误停下。数值0与空字符可相等，但应写空字符表达意图。

## 四、const只读接口

```c
int text_length(const char *text);
```

const char *限制通过text修改所指字符，因此*text='X'或text[i]='X'会被拒绝，读取则允许。不是把原数组永久锁定，也不是所有const写在任何位置含义都一样。通过仍可写的原数组word[0]='B'后，另一个const char*视图能看到BAT；学生曾只答B，教师区分%s整串与%c单字符。

## 五、容量受限复制接口

调用者传目标可写容量，函数不能由char*恢复原数组容量。先求source实际长度，再确认目标能容纳文本字符及结束符；失败返回0且完全不改目标，成功复制含结束符返回1。HELLO需要6格，容量5必须失败。复制次数由来源长度决定，不由目标容量决定；目标10格不意味着可读取来源CAT的10格。

长度应先保存到局部length再复用，避免每轮条件都从头扫描source；此为有意义的效率深化，不是重复字段。学生copy_text提示后完成，八边界教师测试通过。

前缀复制再加limit限制：实际复制数count=min(来源长度,limit)，所需容量count+1。limit是上限，不是必须复制的数量。先检查容量，复制count个文本字符，最后主动写destination[count]结束符。截取HELLO前三字得到HEL时，来源source[3]仍为L，不能直接当结束符复制。limit0且容量1应写目标第0格结束符，得到空串；容量0必须失败。

## 六、结束符改变文本边界，不删除数组后缀

原目标OK只复制H而不补结束符，可能变成HK；成功样例有时碰巧原尾部为零，不代表可以省略终止符。数组R/O/O/M/结束符/2/0/4/结束符中，按字符串读取显示ROOM，后缀204依然存在于数组。

原地分号截断：遇首个英文分号将该格写结束符并返回1，没有分号返回0且不变。学生接受容量参数int marker并硬编码分号的当前变式；char marker通用接口能力未验，不为接口格式重抄程序。循环应同时检查i<容量和text[i]不是结束符；否则可能读到文本结束后的分号并误改尾部。

明确构造char data[5]={'A',结束符,';','X',结束符}只是教师反例。数组容量5，但从首元素开始的字符串A长度1，需两格保存A与结束符。后面的分号不属于该字符串，并非所有字符串末尾都会自动有分号。

## 七、输入/输出格式的不同含义

scanf("%998s", type)限输入最多998；printf("%998s",type)是输出最小字段宽度，不足补空格。不能把输入限制加在printf上。scanf%s接收char*，type在此转换为首元素地址；&type是整个数组地址，类型char(*)[999]不符合格式要求，即使地址数值看起来一样也不能忽略警告。scanf读取失败时不得使用未初始化文本。提示中文分号与实际英文分号不同，测试应明确字符。

已额外问答介绍scanf("%998[^\n]",type)：扫描除换行外字符，含空格，成功后补结束符；换行留在输入流，直接空行会失败。格式里的空白通常跳过空白而非保存。此项仅讲解，未验学生实现；fgets整行输入及恢复留后续系统课程。动态内存malloc/realloc/free仅概念预告，不算已授实现或掌握。

## 八、对象生命周期

生命周期指对象存在的时段；作用域指名字在源码何处可用，不是同一概念。普通自动局部变量reading在所属函数返回后生命周期结束，返回&reading不会延长寿命；调用者指针p仍存在，不等于它原来指向的reading还存在。不能依赖内存似乎仍留12，不能运行后猜固定结果。

```c
int *get_address(void) { int reading = 12; return &reading; }
```

此错误例只做编译诊断、不解引用运行。返回数值reading则调用者可把数值保存到自己的result中，教师验证12。

```c
int *pass_address(int *input) { return input; }
int main(void) {
    int reading = 12;
    int *p = pass_address(&reading);
    printf("%d\n", *p);
    return 0;
}
```

这里返回的是调用者reading的地址，不是形参input自身地址；input结束不意味着main的reading结束。学生起初误判错误例有效，补讲后对照判断此例有效。规则限定普通自动局部对象；static存储期后续另讲，不得推成所有局部对象离开函数都失效。
