## 最小示例与带读

教师示例d8-python-demo.py只含赋值与print，已教师运行验证。temperature = 25无需显式写int；25是整数值，变量名temperature绑定该值。print(temperature)输出变量值，print("temperature")输出引号内文本；print默认换行。本例普通语句不要求行末分号，也不需要main函数外壳。

先给赋值及一次print示例，检查前置：带引号的名字与不带引号的变量分别输出什么，一题一等。新语法先教再要求学生写。
