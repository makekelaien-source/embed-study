## 第一小节：对象与地址

直观模型：内存里的一个存储格，有存放位置，也有当前存放的值。地址好比格子的编号；数值是格子里的内容。真实C对象有类型、大小等性质，地址不是学生随意编的编号。

`int temperature = 25;`定义一个int对象，名称temperature，初始值25。表达式temperature在读取值时得到25；&temperature取得这个对象的地址。赋值temperature=30改变内容，普通局部对象在同一次存续期间地址保持不变。不是不同变量可以任意共用格子的模型。

先看不包含新打印语法的小例并预测：

```c
int temperature = 25;
int backup = temperature;
temperature = 30;
```

只问temperature和backup最后的值，确认复制数值与给同一对象另起名字的区别，再继续。

教师验证例另见demo-2026-10-31-addresses.c；%p配(void*)打印地址作为教师工具写法，转换细节不作为本节独立目标。地址具体数字每次运行可能不同，不要求背诵或预测固定地址。示例运行不算学生能力。

## 指针声明与解引用带读

int *p = &temperature; 中int *p声明指向int的指针，右侧取已有对象地址；表达式*p访问所指对象，*p=30修改temperature。指针自身保存的地址与所指内容区分。下一练习d5-pointer-value.c由学生写，核对数值复制与经地址修改的差别。

## 指针重定向与指针参数

学生预测在原题后p=&backup; *p=40; 得reading5/backup40/*p40正确，带读即时理解，未实跑学生修改版。

下一短例：

```c
void set_value(int *target, int value)
{
    *target = value;
}
/* main内 */
int reading = 5;
set_value(&reading, 40);
```

函数参数target复制传入地址，value复制40；*target=40访问调用者reading。C仍为值传递；并非target和调用处指针是同一个变量，也不称为C改成引用传递。void表示无返回值，修改对象与返回数值分开。

教师临时完整C程序GCC C11/Wall/Wextra/pedantic编译0无诊断，运行reading=40退出0，断言通过；教师验证不记学生表现。下一问题观察函数调用是否修改reading，待学生作答。指针指向有效已有int对象，不涉及空/悬空解引用。
