# Day 1 笔记：变量、数据类型、printf/scanf

## 1. 变量 = 带名字的盒子

程序里的数据要放在内存里。变量就是给一块内存起个名字，方便存取。

```c
int age = 25;
```

拆解这句话：
- `int` —— 盒子的型号（能装什么、占多大地方）
- `age` —— 盒子的名字
- `=` —— **赋值**：把右边的东西放进左边的盒子（不是数学的"等于"！）
- `25` —— 放进去的值

C 是强类型语言：盒子型号一旦定了，就只能装这类东西。

## 2. 三种基本型号（今天只记这三个）

| 类型 | 装什么 | 占几字节 | 例子 |
|------|--------|----------|------|
| `int` | 整数 | 4 | `int n = 10;` |
| `float` | 小数 | 4 | `float h = 1.75f;`（注意尾巴上的 `f`） |
| `char` | 单个字符 | 1 | `char g = 'A';`（单引号！） |

记忆口诀：**int 整数、float 小数、char 一个字符**。
（`double` 是更精确的小数占 8 字节，以后再用。）

## 3. printf 的"空位"（格式说明符）

printf 里的 `%` 是空位，按顺序被后面的值填上：

| 写法 | 填什么 |
|------|--------|
| `%d` | 整数 |
| `%f` | 小数（默认 6 位，太啰嗦） |
| `%.2f` | 小数，只保留 2 位 |
| `%c` | 单个字符 |
| `%s` | 字符串（一串字符） |

`\n` 是换行，放在引号里最后面。

## 4. scanf：从键盘读数据

```c
int n = 0;
scanf("%d", &n);
```

- `"%d"` —— 告诉它我要读一个整数
- `&n` —— **取地址符**：把 n 盒子的"门牌号"交给 scanf，它才能把值放进盒子里
- 忘写 `&` 是新手第一大坑：程序会崩溃

（唯一例外：读字符串 `scanf("%s", name)` 不用 `&`，先记住结论，原理以后讲。）

## 5. 命名规则

- 只能用字母、数字、下划线，不能以数字开头
- 区分大小写：`Age` 和 `age` 是两个盒子
- 起有意义的英文名：用 `celsius` 别用 `x`

## 6. 今日踩坑预告（提前打预防针）

1. 中文标点混入代码 → 昨天已吃过亏，标点必须英文
2. `float h = 1.75;` 会出 warning → 小数常量加 `f`：`1.75f`
3. 字符用单引号 `'A'`，字符串用双引号 `"A"`，不是一回事
4. scanf 忘 `&` → 运行崩溃
5. `int f = c * 9 / 5 + 32;` 里 `9/5` 在 C 里等于 1（整数除法砍小数）→ 涉及小数运算就把变量用 float

3. scanf 读 int 时为什么写 `&n`？（要给 scanf 盒子的地址，它才能放东西）
