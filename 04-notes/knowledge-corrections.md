# 当前讲义与历史记录的知识纠错

> 2026-10-27建立。旧日志/总结保留原文以追溯；当前讲义原位纠正，修订前版本已归档。文字纠正不代表学生已学会，须在基线/后续课复验。

| 原说法/风险 | 准确表述 | 补讲/验证 |
|---|---|---|
| x = x++ 是空操作，旧值一定写回 | C中未定序的修改使其成为未定义行为，不应预测固定值或靠某次运行证明 | 拆开副作用，不运行错误表达式作“固定结果演示”；对照安全计数 |
| 当前标准不允许for括号声明int | C99起允许for(int i=0;...)；本项目C11支持，先写在外只是阶段简化 | 讲块作用域后对比内外声明 |
| 函数必须在调用前定义 | 调用前需正确且可见的声明，定义可以在后 | 正确原型在前、定义在后的小程序 |
| 函数可随意定义在main内 | 嵌套函数为GNU C扩展，不是ISO C标准写法 | 将目标函数放文件作用域，开启Wpedantic核对 |
| void必须打印或改变外界 | void只表示不返回一个值；可以无可观察副作用，可以return; | 区分返回值与副作用 |
| 所有局部变量离开花括号就销毁 | 作用域控制名字可见范围；生命周期/存储期另说，static局部持续整个程序执行期 | 自动/static对照，画名字可见与对象存活两条时间线 |
| 返回int每条路一概必须写return整数 | 普通非void函数应覆盖正常返回路径；main到末尾有特殊规则；非void漏返回且调用者使用其值会有未定义行为风险 | 正常路径检查；初学明确写return，不用特例遮盖漏返回 |
| 传地址说明C不是传值 | 指针值也复制；通过副本指针访问同一对象 | 交换两数并画图 |
| break/continue都只是括号房间 | break结束最内层循环或switch；continue进入最内层循环下一次迭代，if不构成循环目标 | 嵌套switch/循环等到先教再测 |
| sizeof数组可在任意函数内求元素数 | 真数组对象可在所在合适作用域求大小；数组形参会调整成指针，需显式长度 | 同对象在调用者和形参处对比 |
| 编译或示例通过就算掌握 | 编译诊断/功能/独立作答/隔周迁移是不同证据 | 能力表记录H0–HA、边界、解释及复测 |
| 项目阈值只是数值可不改 | 阈值/单位/边界属于需求；变更须同步需求、测试、实现 | 超时边界与无效参数用例 |
