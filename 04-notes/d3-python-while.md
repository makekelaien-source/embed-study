## 先纠正代码块与作用域

缩进决定语句属于哪个代码块，不宜说每缩进四格就创建新作用域。Python的if/for/while块不各自建立独立作用域。函数作用域是后续内容，不提前扩展。

零轮报告仍可输出，是因为计数等变量在循环前已赋初值，三个print在循环外；range(0)跳过循环体后仍顺序执行它们，和零轮提示if是否存在无关。

## 最小例子

```python
count = 0
while count < 3:
    print(count)
    count += 1
print("结束")
```

先判断count<3，真则进入，执行完回到条件再次判断；假则跳过循环体继续后续。冒号与4空格缩进沿用已学规范。教师验证正常输出0/1/2/结束；初值3时只输出结束。不是每个while都必须递增整数，关键是循环体按业务推动状态，让终止条件有机会成立。

## 输入驱动的最小带读（教师验证后使用）

```python
temp = int(input("温度："))
while temp != -999:
    print(temp)
    temp = int(input("温度："))
print("输入结束")
```

首读让条件有输入值；循环尾部重读推动条件变化。教师实际测试18/30/-999只回显18/30再结束，首项-999直接结束，均退出0无stderr。学生先解释第二次input的作用，再布置分类统计目标，不以带读代替独立完成。
