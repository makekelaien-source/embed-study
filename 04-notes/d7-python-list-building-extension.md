## 最小带读

```python
selected = []
selected.append(5)
selected.append(9)
print(selected)
```

空列表可逐项追加，append把一个元素放到末尾，原列表本身发生改变；当前不要写selected=selected.append(...)，append的返回值None可在出现该错误时局部补讲。先预测，再教师/学生运行，不能以教师验证替代学生能力。
