# D3 讲义：if / else —— 让程序学会「分岔」

> 对应计划：W2 控制流热身。只用已学过的语法：变量、printf/scanf、%、==、&&、||。
> 配套代码：`03-code\d3-demo.c`（编译：`.\go d3-demo`）

## 1. 什么是分支？（类比）

水流到岔路口，闸门决定往左还是往右。程序也一样：
**先看一个条件（闸门），条件成立就走这条路，不成立走另一条路。**

到目前为止你写的程序都是「一条道走到黑」：从上到下一行行执行，没有岔路。
今天加的就是岔路。

## 2. if：单个闸门

```c
if (n % 2 == 0) {
    printf("偶数\n");
}
```

读法：「如果 n 除以 2 余数等于 0，就执行大括号里的话。」

拆开看每个零件：
- `if` —— 关键字，意思是「如果」
- `(n % 2 == 0)` —— 条件，写在**小括号**里，结果只能是「成立」或「不成立」
  - `%` 是昨天学的取余：`7 % 2` 得 1，`8 % 2` 得 0
  - `==` 是昨天学的比较：两边相等得 1（成立），不等得 0（不成立）
- `{ ... }` —— 大括号，把「成立时要执行的几行」包起来

**坑 1：`if (n % 2 = 0)` 是错的。** 一个 `=` 是赋值，两个 `==` 才是比较。
在 if 里写单 `=`，编译器要么报错，要么把 0 赋给表达式——条件永远不成立。

**坑 2：条件的小括号不能省。** `if n % 2 == 0` 编译不过。

## 3. if / else：两条路

```c
if (n % 2 == 0) {
    printf("偶数\n");
} else {
    printf("奇数\n");
}
```

读法：「条件成立走 if 这条路，**否则**走 else 这条路。两条路必走其一，不会都走。」

## 4. else if：多条路

```c
if (score >= 90) {
    printf("优秀\n");
} else if (score >= 60) {
    printf("及格\n");
} else {
    printf("不及格\n");
}
```

读法：从上往下**逐个**试条件，**第一个成立的就走，后面的全部跳过**。

注意：`score = 95` 时第一个条件成立，走「优秀」，**不会**再检查 `>= 60`。
所以顺序很重要：先写严格的（>=90），再写宽松的（>=60）。写反了 95 也会被归进「及格」。

## 5. 条件可以组合（复习昨天的 && 和 ||）

```c
if (score >= 60 && attendance >= 80) {
    printf("可以参加考试\n");
} else {
    printf("不能参加\n");
}
```

- `&&`：两边**都**成立才成立（且）
- `||`：任意一边成立就成立（或）

## 6. 今天的固定套路（练习就用这个骨架）

```c
#include <stdio.h>

int main(void)
{
    int n = 0;

    printf("请输入一个整数: ");
    scanf("%d", &n);          // 别忘了 &

    if (n % 2 == 0) {
        printf("%d 是偶数\n", n);
    } else {
        printf("%d 是奇数\n", n);
    }

    return 0;
}
```
