# 11月12日教师使用说明（不是学生目标核心答案）

按一次一题呈现，学生预测后才用本文件核对。不把本说明里的答案主动贴进学生练习。

## 复习答案与提示分级

- static对象在函数返回后仍存在，局部名字不在main作用域内；不能用“离开函数对象就没了”解释static。学生能否独立重新解释待课堂证据。
- &返回保留位权的整数；例如18&16是16，而(18&16)!=0是1。二者不混为同一道返回契约。
- 右移向右，18u>>1为9；左移1为36，前提无丢弃。位图要保留位号意义。
- pointer-demo先把a从25改26，b仍25；在此基础上让p=&b再increase，b变26、a仍26。p改指向不意味着a跟着改变。
- by_value内部99/返回后a25，by_pointer后a99。形参无论对象还是指针都是值传递，关键是复制了对象值还是地址值。

K1/K2/K3学生完整实现不写在本文件；教师只给业务契约、示范小例和分级提示，学生写新增核心。若需完整代修，另存答案并登记HA。

## sample-main退出码

| 退出码 | 含义 |
|---:|---|
| 0 | 内部全部检查通过，输出SAMPLE_CHECKS=PASS |
| 1 | sample_set_value的目标成员或数据保持错误 |
| 2 | 高温刷新等级/报警位错误 |
| 3 | 低温刷新等级/报警位错误 |
| 4 | 原快照受影响 |
| 5 | 温度19边界或其他成员保持错误 |
| 6 | 温度20边界或其他成员保持错误 |
| 7 | 温度29边界或其他成员保持错误 |
| 8 | 温度30边界或其他成员保持错误 |

这些是教师验收进程退出码，不是sample_refresh的返回值；后者返回void。开始验收前先解释退出码归属。核心为空白时不能完整链接，不能因支架通过分编译就写成学生功能通过。
