# 11月13日教师说明（条件备课，未授）

## 首讲检查答案

- 编号上限1000不能选uint8_t，最大255；uint16_t能覆盖。不能仅说“16更大”而不解释业务上界。
- 当前平台uint8_t 255加1的中间表达式是int 256；转换回uint8_t为0。固定类型的存储范围不能直接当作所有表达式的计算宽度。
- 数组第二个对象readings[1]改值不会改第一个对象，指针指向的是数组中的真实元素。
- const数组形参限制通过该参数写对象，不负责冻结所有别名；count0允许NULL时不得读取samples[0]。
- flags1、mask3：ANY真，ALL假；flags3、mask3：两者都真；flags4、mask3：两者都假。判断次数与匹配记录数不同。
- mask0在本题不接受（调用者保证1至7），不要把它临时作“出错返回0”。计数0有真实无匹配含义。

学生目标count_flagged/sample_set_batch的完整实现仍留空白；不把测试支架当成目标答案。

## filter-main退出码

| 退出码 | 含义 |
|---:|---|
| 0 | 所有检查通过，输出FILTER_CHECKS=PASS |
| 1 | mask3 ANY计数错误 |
| 2 | mask3 ALL计数错误 |
| 3 | 单位mask4 ANY计数错误 |
| 4 | mask7 ALL无匹配错误 |
| 5 | NULL/count0 ANY路径错误 |
| 6 | NULL/count0 ALL路径错误 |
| 7 | 只读筛选改写了原flags |
| 8 | 批量置第2位错误 |
| 9 | 批量清第1位错误 |
| 10 | 批量更新改变了温度/id/level等其他成员 |

sample_set_batch返回void，不是返回这些码。它们属于教师入口进程；count_flagged返回的是匹配条数。每次批量调用的输入域合法，不增加未约定的非法位号要求。教师还应按实际追加其他成员全部保持和高位保持用例，不把单一入口通过泛化成无限输入正确。

## 学生排错目标

先给出被修改的准确一行：MATCH_ALL本应全部满足，植入版却改成至少一个。学生选flags1/mask3揭错；两版TRUE/FALSE/数值结果要分清。若循环改成i<=count，需要定位越界条件，但不要实际依赖越界程序有固定输出。

数组更新成本O(n)，返回计数不需要拷贝整数组。比较位掩码只能说明选中设备位；不能推出真实电路一定已动作。
