# Day8补充：整数后再读一个字符

## 目标与前置

学生主动发现scanf的%d会接受小数的整数前缀，明确问如何修改。本例是按请求提供的教师完整示范（HA），不计学生独立实现。

前置：int、scanf返回赋值个数、if与&&。两个新点：char存一个字符；%c读取一个字符（包括空格或换行）。字符用单引号，换行写作'\n'。

## 本例约定与边界

仅单次输入，数值须在int范围内；整数后直接回车，不允许尾部空格。允许%d原本接受的前导空白和正负号。不是通用整行输入校验：不处理超范围整数、不处理循环恢复、也不接受无换行的文件末尾。完整通用校验后续学字符串、fgets与strtol。

## 示例与逐行含义

完整示例单独放在d8-input-tail-demo.c，不覆盖学生练习。

- int a：接收整数；char tail：接收紧随其后的一个字符。
- scanf("%d%c", &a, &tail)：先读整数，再立刻读一个字符；%d与%c之间不要加空格，空格会改变空白处理方式。
- b == 2：两个变量均成功赋值；tail == '\n'：紧接整数的是换行。
- &&短路：前者不满足不会读取tail；失败分支也不读取a。

## 预测、测试与复测

3.5：a读3，tail读'.'，b为2但换行条件不成立；12abc：tail为'a'，拒绝；90加回车：tail为换行，接受。不是把小数四舍五入或截断转换。

教师验证见当日日志。学生可按示例修改自己的单次输入练习，此处是示范后仿写；不立刻反复口头测同点。后续复测用新情境，不以本示例升级独立完整校验能力。
