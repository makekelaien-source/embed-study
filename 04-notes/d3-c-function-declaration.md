# D3最后单元：C函数声明与定义

2026-10-29学生明确“再学一个C的新知识就结束今天”，本次依学生要求从Python转回C，作为连续语言块规则的用户明确例外，原预案不改写。只教函数原型这一新概念，结束本单元后日终，不再追加其他知识。

## 前置与目标

学生已写标量函数并使用返回值；补函数调用前声明可见性的基线。正确区分声明与定义，能把定义放在main之后，在main之前提供匹配的原型。

## 最小例子

```c
#include <stdio.h>

int increase(int value);

int main(void)
{
    printf("%d\n", increase(3));
    return 0;
}

int increase(int value)
{
    return value + 1;
}
```

声明int increase(int value);告诉编译器名字/返回类型/参数类型，不提供函数体，不执行调用。末尾分号是声明组成部分。定义包含花括号函数体，说明调用时执行的动作；本例定义在main后仍合法，因为main中的调用前已有正确可见原型。

不是所有函数定义都必须放main前；原先先定义再调用也合法，定义本身同时提供声明。函数声明和定义的返回/参数类型必须匹配。C11不允许隐式函数声明；具体编译器可能以警告兼容接受，不能把偶然生成exe当合规。
