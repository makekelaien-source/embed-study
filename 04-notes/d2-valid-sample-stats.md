# D2综合实践：有效采样统计

## 目标与时段

属于C主线，计划45–60分钟含独立实现/批改/边界解释，按真实分段计时，提前完成按证据进阶，不补造时长。前置来自已有学生文件：数组遍历、故障计数、求和、float转换与%.2f、if分支。新应用是标记值不参与数值统计，以及无有效样本时不除零。

## 完整需求

学生文件03-code_codex/d2-valid-sample-stats.c，助手先建立空白文件，核心学生写。

固定5个整数样本{23,-999,25,-999,24}。只有-999表示故障，其他值（含0和其他负数）均有效。最后输出4行：故障次数、有效次数、有效总和、有效均值（保留两位小数）。均值除数是有效次数，不是固定5。无有效样本时前三行5/0/0，第四行打印“无有效数据”，不能执行除零。

原数组预期2/3/72/24.00。可参考已教笔记和旧作，但不要复制教师目标答案；完整过滤实现不在讲义给出。按新授课偏好不逐行口问初始化，先学生完整实现再诊断。

## 教师短例与测试

短例next-day-demo/d2-mean-guard-demo.c只演示均值保护：total=7,count=2输出3.50，count=0输出no valid data；无数组过滤或目标计数核心。教师实际编译验证后，按需要解释，不提前作为目标完整答案发出。

助手用临时副本批测并保留学生原作：

| 数据 | 故障/有效/总和/均值 |
|---|---|
| 23,-999,25,-999,24 | 2 / 3 / 72 / 24.00 |
| 1,2,3,4,5 | 0 / 5 / 15 / 3.00 |
| -999,-999,-999,-999,-999 | 5 / 0 / 0 / 无有效数据 |
| 1,2,-999,4,-999 | 2 / 3 / 7 / 2.33 |
| -2,-999,-8,0,-999 | 2 / 3 / -10 / -3.33 |
| -999,-999,-999,-999,6 | 4 / 1 / 6 / 6.00 |

输入均为小整数，本题不承担任意大整数累加溢出验证。测试执行标教师，学生设计/修改/解释单独记。

## 批改与完成条件

优先看故障是否被加进总和、有效个数是否只数有效项、是否先转换再做除法、零有效分支是否确实避免除法。每轮只指出1–2个根因，学生修订；不为风格强制重抄。通过后让学生解释一个真实反例和修正，不重新遍历每个简单常量。约11-04新情境复测待做。
