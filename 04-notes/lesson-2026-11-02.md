## 单元A：Python函数

前置输入转换、条件、循环已有Python证据；def和return尚未系统授。最小带读示例：

```python
def add_one(value):
    return value + 1

answer = add_one(4)
print(answer)
```

预测返回值和打印位置，再讲形参不写int、缩进表示函数体、return把结果交回调用者。不要把return等同print；所有预期数值路径都返回数字，None只作后续诊断点。

学生任务：实现celsius_to_offset(value)，返回value-20，不打印；在调用处处理显示。正常25→5、20→0、-5→-25。核心布置前创建03-code_codex/d7-python-function.py空白。H0尝试后再给局部提示，教师代跑机械用例。

## 单元B：列表与遍历

直观例values=[4,-2,7]，三个元素，下标0/1/2；len(values)为3。Python列表不是C数组，len读取容器当前元素数量，不扫描C结束符。短例先预测values[1]、len及for value in values每次拿到什么。不要引入未授推导式/切片。

任务：建立一个列表并用for输出每个元素，在末尾报告len；输入固定由题目给，不在此塞字符串拆分输入。空列表遍历0次，不能访问values[0]。学生目标d7-python-list.py先建空白。

## 单元C：函数接收列表

业务：一组测量值中，统计达到阈值的数量。接口def count_at_least(values, threshold)。返回满足value>=threshold的元素数，不打印，不改values。main负责建立列表/调用/显示，不使用未教的列表推导式，不依赖旧函数复制。

验收[2,5,5,9],5→3；[],5→0；[5],5→1；[4],5→0；[-3,-1,0],-1→2。先用新语法实现已理解的计数逻辑，教学目标为Python函数/列表接口，不把换语言后重复算法记为C新增掌握。目标d7-python-list-function.py布置前建空白。

## 单元D：列表对象与名字

```python
first = [1, 2]
second = first
second[0] = 9
print(first)
second = [7]
print(first)
```

新点：两个名字可引用同一可变列表；修改元素与让名字改指另一个列表不同。预期两次first均为[9,2]，教师验证后先让学生预测。此例不要求把Python解释为C的&或*，也不引入深浅复制细节。作用域/生命周期用Python规则解释，不能直接搬用C普通局部对象出函数立刻失效结论。
