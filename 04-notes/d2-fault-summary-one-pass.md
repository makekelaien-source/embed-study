# 故障汇总：一次遍历的局部示范

学生先完成双循环方案并主动提出更简洁写法，教师在此提供局部参考；保留学生原作。目标是同时统计全部故障次数并保留首次下标。

沿用循环前a=0、location=-1，可将两次循环替换为：

```c
for (int i = 0; i < 5; i++)
{
    if (sample[i] == -999)
    {
        a++;
        if (location == -1)
        {
            location = i;
        }
    }
}
```

每遇故障都累计，但只有尚未记录位置（location==-1）才设置下标。第一次设置后保持，后续继续计数，不break。初始化与最终printf仍在循环外。

区别：双循环先找到第一个、再完整计数；最坏检查2×5个元素，一次遍历检查5个。两者随数组长度增长的工作量都仍是线性，不能夸称数量级改变或未测的运行时间倍数。

教师临时副本验证六组：两故障2/1、无故障0/-1、全故障5/0、仅末尾1/4、仅首位1/0、其他负数0/-1，全部通过、编译无诊断；学生保存版双循环原样本2/1也通过，原文件未改。该优化为教师示范，不算学生独立优化。
