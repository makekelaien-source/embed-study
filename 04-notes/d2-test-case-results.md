# D2学生测试设计与教师执行记录

## TC01：达到连续3次就报警

| 项目 | 记录 |
|---|---|
| 要检查的需求 | 最长连续故障恰好3次时必须报警（>=3） |
| 输入 | F F F N F F N N，F=-999，N本次映射20 |
| 预期结果 | 最长连续3次，报警 |
| 实际结果 | 最长连续3次，报警 |
| 是否通过 | 本用例通过 |
| 输入设计者 | 学生；教师给检查目标与预期框架后，学生自行选序列 |
| 执行者 | 教师，临时副本替换数据后编译运行，保留学生原作 |

这是一次完整的“需求→输入→预期→执行→对比”。仅证明此用例符合要求，不证明所有需求都已覆盖。预期由教师在教学框架中给定，不能据此记学生独立设计完整测试；学生自行选择恰好3的序列符合目标。

## TC02：低于报警阈值

| 项目 | 记录 |
|---|---|
| 要检查的需求 | 最长连续故障只有2次时不应报警 |
| 输入 | F F N N F F N F，F=-999，N本次映射20 |
| 预期结果 | 最长2次，正常 |
| 实际结果 | 最长2次，正常 |
| 是否通过 | 本用例通过 |
| 输入与预期设计者 | 学生；教师给最长2次的检查目标，学生选择序列并写对预期 |
| 执行者 | 教师，临时副本编译运行，保留学生原作 |

与TC01配合，检查了阈值3的下侧2及阈值本身3；其他需求未因此自动证明。学生本次在给定测试目标下能选择序列并确定预期，尚非独立制定完整覆盖计划。
