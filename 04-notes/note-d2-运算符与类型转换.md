## 一、运算符：就是「计算器上的按键」

C 里最常用的：

| 运算符 | 意思 | 例子 | 结果 |
|---|---|---|---|
| `+ - * /` | 加减乘除 | `7 / 2` | **3**（不是 3.5！见下面坑①） |
| `%` | 取余数（除完剩下的） | `7 % 2` | 1 |
| `=` | 赋值：把右边的值装进左边 | `a = 5` | |
| `+= -= *= /=` | 简写：`a += 3` 就是 `a = a + 3` | | |
| `++ --` | 自增/自减 1：`i++` 就是 `i += 1` | | |
| `== !=` | 判断相等/不相等（注意是两个等号！） | `a == 5` | 真(1) 或 假(0) |
| `< > <= >=` | 比大小 | `a > 3` | 真(1) 或 假(0) |
| `&& \|\| !` | 并且、或者、不 | `a > 0 && a < 10` | 真(1) 或 假(0) |

**最容易混的**：`=` 是「放进去」，`==` 是「问一问」。
类比：`=` 像你把 5 块钱放进抽屉；`==` 像问「抽屉里是 5 块吗？」

## 二、类型：整数盒子和带小数盒子

- `int`：只能装整数（…-1, 0, 1, 2…）
- `float`：能装带小数的（3.14、-0.5）

类比：int 是「整箱装」，float 是「散装」。

### 坑①：整数 ÷ 整数 = 整数（小数部分直接扔掉）

```c
5 / 2   →  2     // 不是 2.5！int 盒子装不下 2.5，小数被砍掉
5 % 2   →  1     // 想知道被砍掉的部分？用取余
5.0 / 2 →  2.5   // 只要有一个是带小数的，结果就是带小数的
```

### 坑②：赋值时类型会自动转换（隐式转换）

```c
int a = 3.9;      // 3.9 塞进 int 盒子 → 变成 3（小数被砍，不是四舍五入！）
float b = 5 / 2;  // 先算 5/2=2（整数除法），再把 2 变成 2.000000
                  // 想要 2.5 要写 5.0/2 或 (float)5/2
```

### 强制类型转换：手动换盒子

```c
(float)5 / 2   →  2.5   // 先把 5 变成 5.0，再除
```

类比：像图纸上的比例尺换算——1:100 的图上量 2cm，实际是 200cm。数字没变，「单位」变了。

## 三、scanf 回顾（d1 的坑，今天继续用）

```c
int n;
scanf("%d", &n);   // & 不能丢！&n = 「n 这个抽屉的地址」，scanf 才知道往哪放
```

- `%d` 读整数，`%f` 读带小数（float 用 %f，scanf 里 float 也要 &）
- printf 里 `%f` 默认打印 6 位小数；`%.2f` 只留 2 位

## 四、今天两个小程序的思路

### 交换两杯水

要交换两杯水，必须找第三个空杯：
```
tmp = a;  a = b;  b = tmp;
```
不用第三杯的写法（选做）：`a = a + b; b = a - b; a = a - b;`

### 秒数换算

1 分钟 = 60 秒，1 小时 = 3600 秒：
```
小时 = 总秒数 / 3600      （整除，正好是小时数）
剩下 = 总秒数 % 3600      （除完剩下的秒）
分钟 = 剩下 / 60
秒   = 剩下 % 60
```
这里 `/` 和 `%` 配合用，正好把「砍掉的部分」和「剩下的部分」都拿到。
