## 本单元首讲

目标：知道指针可指向原数组中间，不必复制数组；返回/保存这个地址不创建新文本，数据仍属于原数组对象。仅用已知字符数组、const指针、赋值和printf。

对char指针p，加整数n表示向后移动n个字符元素，结果是新指针值，不修改原数组，也不自动改变p。p+n与&p[n]在所指位置有效时指向同一元素。结果只能落在同一数组元素范围内或恰好尾后一格；尾后指针不能解引用。用%s输出还要求从该位置起能在有效范围内遇到结束符，不能把任意有限片段当字符串。

最小示例line为MODE AUTO，line+5指向A，%s从A读到原数组末尾的结束符，输出AUTO。line[5]改X后，同一part再读得到XUTO。part不是独立文本副本；通过const指针不能写字符，但拥有可写原数组的调用端仍能改变它。

原数组寿命仍决定借用地址可用多久：main的数组在main尚未退出时存在；某函数中的普通自动局部数组不能因返回地址而延长寿命。旧寿命规则仅作必要前置，不重做旧复制函数。

下一步先以一个指针偏移/原数组修改的短预测确认别名关系，再讲返回const char*接口；需要旧扫描时直接包含现有头并链接现有实现，不要求学生复制旧函数。新任务出题前再创建空白学生文件并完整说明NULL/非NULL返回契约。

## const指针的两种限制

const char *p限制通过p写字符，不固定p值，也不冻结原可写数组；char *const p固定指针值而不使原对象变只读；const char *const p两种限制并存。char const *p和const char *p等价。学生主动追问过多次，已讲解并用教师编译对照验证，未独立检查这三种组合。

## 返回指针的新语法

const char *move_one(const char *text)表示返回一个指向只读访问字符的指针值。形参text接收地址副本；return text+1把偏移后的地址值交给调用端，既不复制原数组，也不创建文本。最小例预设text指向仍存活、至少含一个普通字符的字符串，GO调用后指向O，输出O。调用结束使形参text的局部名字结束，不会结束调用者word数组的寿命；借用地址能用多久取决于它所指对象。教师示例已严格构建运行验证。随后用主数组修改的短预测确认，不提前运行学生变式。

## 学生任务：返回首分隔符后的借用字符串

接口const char *after_delimiter(const char *text, int capacity, char delimiter)。必须复用已写token_prefix_length，不重抄扫描循环，不复制文本。输入capacity非负；为0返回NULL，不访问text，允许text为NULL；为正时由调用者保证text指向有效C字符串且首结束符位于这capacity格以内。此项前提比旧有限字符片段扫描更强，因为成功结果要当字符串使用。

若delimiter为结束符，返回NULL（本接口不把结束符当业务分隔符）。否则在首结束符之前找到第一个分隔符，返回它后一个字符的地址；若没有找到则返回NULL。分隔符后立即结束时，成功返回指向原结束符的非空指针，代表空后缀；与NULL未找到不同。函数不打印、不读输入、不修改源、不创建局部文本副本。返回地址仅在原数组对象仍存活且调用方按有效字符串使用时可用；源数组后续变动可反映在借用视图中。

验收：RUN AUTO/9/空格返回源下标4，后缀AUTO；RUN空格/5/空格返回源下标4的结束符，后缀为空；/GO/4/斜杠返回源下标1，后缀GO；RUN/4/空格返回NULL；A/B/C/6/斜杠返回源下标2，后缀B/C；NULL/0/斜杠返回NULL；GO/3/结束符返回NULL。教师还要检查返回地址确实属于原数组、源不变，学生只实现新接口和独有保护声明；调用/批测由教师准备。
