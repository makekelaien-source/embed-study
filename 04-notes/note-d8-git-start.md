## 本单元目标与前置

前置：PowerShell路径、源码与生成物区别。目标是由学生创建本地仓库，查看差异、选择文件并提交一个可解释的版本。每次只发当前步骤，不一次贴整套命令。

先用游戏存档点类比提交：commit记录选定内容的版本；仓库是管理这些版本的空间。类比边界：init只建立仓库，不产生已提交版本，Git不会自动保存未暂存/未提交的全部修改；本地commit不等于上传到外部。

## 按学生操作推进

1. 当前初练必须位于D:/Apostgraduate/opencode/embed-study根目录；学生Set-Location后执行git init -b main并提交输出。教师不代初始化，若已有仓库则先检查其真实根目录，不嵌套创建。
2. 教师核对.git所在位置并读取status，区分工作区文件与仓库管理目录；后续先教忽略策略，再做add。初次只选.gitignore和学生首个Python脚本作为小提交，避免一上来git add .。
3. 学生创建.gitignore，排除exe/o/obj/pdb、Python缓存/虚拟环境和真实.env等；README/源码/CSV及测量证据不一概忽略，示例.env可显式允许。不得把忽略等同删除文件，也不掩盖已跟踪秘密。
4. 讲工作区→暂存区→提交三个状态，先检查git status，再git add选定文件；学生读git diff --cached解释即将保存的内容，之后才commit。
5. 当前user.name/user.email未配置；到提交前讲清仅是提交署名，问学生希望本仓库使用的姓名和邮箱（GitHub隐私邮箱如有可用），只设仓库局部配置。不得编造私人邮箱或擅自改全局设置，也不要求创建外部账号。
6. 学生执行首次本地commit，用git log -1和status验证。之后对已教脚本作小修改，用diff解释，再由学生选择是否提交；不使用破坏性reset/clean/restore覆盖当前代码，不进行远程发布。

## 证据与收口

每步记录学生命令/实际输出与提示，教师读取验证另列；只安装Git、init成功或教师代命令都不算学生会独立版本管理。记录首次提交hash/选中文件，保留未提交文件状态，不把只提交两文件说成全项目已备份。局部身份信息避免复制到日志。

本地初练不需要桌面软件；如确需打开编辑器或其他GUI则先用desktop-continuity，不能因已启动就算完成。学生暂停时保存当前阶段，下次从add/配置/commit的真实断点继续。
