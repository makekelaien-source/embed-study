## 一、while —— "检票进站"

### 1. 它解决什么问题

for 适合"事先知道要跑几圈"（从 1 数到 100）。
但很多事**事先不知道次数**，只知道"什么时候该停"：

- 让用户输密码，输错就重输 —— 不知道他会错几次
- 传感器读数大于 100 就报警，一直盯着 —— 不知道要盯多久

这种"只要条件成立就一直做"的循环，用 while。

### 2. 类比：检票进站

闸机规则："**只要**票有效，**就**放行通过；票无效，循环结束。"
每次通过前都要重新验一次票（重新检查条件）。

```c
while (条件) {
    做的事;
}
```

执行顺序：检查条件 → 成立就做身体 → 再检查 → ... → 不成立就结束。

和 for 对比：while 只是把 for 的"第 2 段"单独拿出来反复用，
起点和 +1 要自己写在外面。

### 3. 完整例子：存钱到攒够为止（可直接运行）

```c
#include <stdio.h>

int main(void)
{
    int money = 0;
    int month = 0;

    while (money < 1000) {      /* 只要没攒够 1000 就继续 */
        money = money + 100;    /* 每月存 100 */
        month = month + 1;      /* 月数 +1 */
    }
    printf("存了 %d 个月, 共 %d 元\n", month, money);
    return 0;
}
```

- 循环前 money 和 month 必须先给初值（相当于 for 的第 1 段）。
- 身体里必须有让条件**越来越接近不成立**的语句，否则死循环。

### 4. 例子：输入校验（嵌入式里超常用）

```c
#include <stdio.h>

int main(void)
{
    int n = 0;
    printf("请输入 1~10 之间的数: ");
    scanf("%d", &n);

    while (n < 1 || n > 10) {       /* 不在范围内就重输 */
        printf("输入不对, 请重新输入: ");
        scanf("%d", &n);
    }
    printf("收到: %d\n", n);
    return 0;
}
```

注意：身体里**必须再 scanf 一次**，否则 n 永远不变，无限循环。

### 5. 坑

**坑 1：死循环** —— 身体里忘了改变条件变量（忘了 `month = month + 1`
或忘了再 scanf），条件永远成立，程序卡死。Ctrl+C 可强行终止。

**坑 2：while 后面多写分号** —— 和 for 一样，`while (n < 10);`
等于"空转检查，什么都不做"，常常直接卡死。
**while ( ... ) 后面永远直接跟 {。**

**坑 3：进循环前忘了给初值** —— `int money;` 不写 `= 0`，
第一次检查时 money 是垃圾值，可能一次都不循环。

## 二、do-while —— "先尝一口再决定"

### 1. 它和 while 的唯一区别

while：**先检查，后做**（条件不成立可以一次都不做）。
do-while：**先做一次，后检查**（身体至少执行 1 次）。

```c
do {
    做的事;
} while (条件);      /* 注意: 这里末尾有分号! */
```

类比：自助餐试吃——先尝一口（做），再决定要不要再来一口（检查）。

### 2. 完整例子（可直接运行）

```c
#include <stdio.h>

int main(void)
{
    int choice = 0;

    do {
        printf("1=继续 0=退出: ");
        scanf("%d", &choice);
    } while (choice != 0);

    printf("已退出\n");
    return 0;
}
```

菜单至少会问一次——就算用户一上来就输 0，也先问过了。
这正是菜单类程序的典型写法。

### 3. 什么时候用哪个

| 写法 | 特点 | 典型场景 |
|------|------|---------|
| while | 可能一次都不做 | 攒钱、盯传感器 |
| do-while | 至少做 1 次 | 菜单、"先问一次再校验" |

初学阶段 90% 用 while，见到 do-while 能认出来就行。

**坑：do-while 末尾的 `while (...);` 分号不能省**，
这是 C 里唯一以分号结尾的循环结构。

## 三、嵌套循环 —— "楼层 × 房间"

### 1. 概念

循环身体里再放一个循环，就是嵌套。

类比：一栋楼查房。**外层**一层一层上楼（楼层 1~3），
**每到一个楼层，内层**把 1~4 号房间全部查一遍。

```c
int floor = 0;
int room = 0;

for (floor = 1; floor <= 3; floor = floor + 1) {     /* 外层: 楼层 */
    printf("--- 第 %d 层 ---\n", floor);
    for (room = 1; room <= 4; room = room + 1) {     /* 内层: 房间 */
        printf("  检查 %d-%02d 房\n", floor, room);
    }
}
```

`%02d` 是 printf 的小技巧：数字不足 2 位就前面补 0，
1 号房打印成 `01`。

执行规律：**外层走 1 步，内层从头到尾跑完一整轮。**
外层 3 次 × 内层 4 次 = 内层身体总共执行 12 次。

### 2. 经典例子：九九乘法表（可直接运行）

```c
#include <stdio.h>

int main(void)
{
    int i = 0;
    int j = 0;

    for (i = 1; i <= 9; i = i + 1) {
        for (j = 1; j <= i; j = j + 1) {
            printf("%d*%d=%-4d", j, i, i * j);   /* %-4d: 左对齐占 4 格 */
        }
        printf("\n");    /* 内层跑完一整轮才换行 */
    }
    return 0;
}
```

注意 `printf("\n")` 在**内层外面、外层里面**——
每查完一层（一行）才换行。放错位置是最常见的嵌套错误。

### 3. 坑

**坑 1：内外层用同一个变量** —— 外层 i、内层也 i，
内层把 i 改光，外层直接乱掉。内外层变量**必须分开**（i 和 j）。

**坑 2：换行位置放错** —— `printf("\n")` 写进内层里，
结果每个格子都换行，乘法表变成竖条。

**坑 3：内层忘了重置起点** —— 内层循环变量每轮都要从 1 开始
（写在 for 的第 1 段里就自动重置；换成 while 要自己重置）。

## 四、break 与 continue —— 循环里的两个开关

- `break;`：整个循环**立刻结束**，跳到循环外面。（switch 里学过的 break，在循环里意思相通：离场）
- `continue;`：**本轮**不做了，直接跳到下一轮。

```c
for (i = 1; i <= 10; i = i + 1) {
    if (i == 5) {
        break;       /* 数到 5 整个循环结束, 6~10 不做了 */
    }
    if (i % 2 == 0) {
        continue;    /* 偶数跳过本轮, 不执行下面的 printf */
    }
    printf("%d\n", i);   /* 打印 1 3 7 9 */
}
```

嵌套循环里的 break **只能跳出内层这一层**，外层照旧。
