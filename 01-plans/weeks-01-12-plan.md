## 前两个学习周的教学单元

Day8函数/猜数字及scanf单元已于10-27提前开展，已有证据不重复计数，10-28从数组接续；下列旧知识只在新情境有缺口时补强。一个内容单元不等于全天学习总量。

| 单元 | 内容 | 学生任务/检查 |
|---|---|---|
| L1-1 | 接续断点、一维数组声明/长度/下标 | 短问循环前置，预测元素；核心由学生写 |
| L1-2 | 遍历、最大值/均值、边界 | 单元素、重复值；空区间先定义策略 |
| L1-3 | Git init/add/diff/commit | 学生创建本地仓库、排除exe/凭据并解释一次提交 |
| L1-4 | 冒泡与循环边界 | 手走一轮再实现，测排序/逆序/重复 |
| L1-5 | 读警告、断点、局部量与调用栈 | 学生定位一个已教范围内错误，解释证据 |
| L1-6 | 函数/数组新情境及复盘 | 区分提示等级，安排延迟复测，不重复猜数字题 |
| L2-1 | 对象、地址、&、*、指针类型 | 画内存图，先预测读写；不解引用未知指针 |
| L2-2 | 指针参数与值传递 | 交换两数，解释复制指针值与修改所指对象 |
| L2-3 | 数组参数、显式长度与sizeof | 统计函数，空区间/长度1/多元素 |
| L2-4 | 字符数组、终止符、容量 | 教完再练受限输入；不把成功转换等同整行合法 |
| L2-5 | 数据统计接口 | 函数职责与返回值；头文件细节在L3展开 |
| L2-6 | 新变式及器材核对 | 列已有/待购，采购由学生决定 |

## 同步课程与证据

辅助语言/工具每周5h：L1–6 Python3h＋Git/调试2h，L7–12 Python3h＋Linux2h。Python从基础、函数、容器、文件和异常处理走到CSV与串口，逐周任务见[语言计划](language-and-tools-plan.md)。每周另有算法2h、计算机基础3h、测试/文档复盘5h；与主线15h合计30h，不重复计时。

算法由数组/字符串到队列/链表与查找排序；计算机基础依次联系数制/位宽、编译链接、栈堆/生命周期、中断/volatile、计时与吞吐。每周保留解释和学生错误定位，每4学习周评估。

开课前读[教学规范](teaching-guide.md)，先准备讲义、验证短例再授课。Fibonacci可作循环新变式，杨辉三角为选做。硬件清单和验收见[项目需求](../05-projects/realtime-terminal/README.md)与[验收表](../05-projects/realtime-terminal/acceptance.md)；桌面软件使用desktop-continuity。
