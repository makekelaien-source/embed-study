## 1. 两秒的定义与实现路线

两秒指“用户最后一个实际语音结束 → 音箱首次发出有内容的回应”。提示音、预录的‘让我想想’以及纯文件生成不算聊天达标。静音时没有可听首声，不计 response_s。

下表为工程预算，均不是实测或保证：

| 阶段 | 目标预算 | 改进手段 | 本次状态 |
|---|---:|---|---|
| 说完判定 | 0.55 s | 保留停顿容忍；噪声门槛减少误启动 | 电平门槛已实现，真人待测 |
| 末尾识别 | 0.25 s | 对比流式识别，用户说话时完成大部分计算 | 待选型/移植；当前仍为离线 SenseVoice |
| 模型到首段文字 | 0.65 s | 对照首段8/12/16字；检查真实首token与输入处理时间 | 新增8/12字候选入口；默认仍16 |
| 首段合成 | 0.40 s | 对照更短首段及轻量音色；保留可懂度 | 普通回复待板测；音量指令确认音已预生成 |
| 播放提交/缓冲 | 0.15 s | 测真实音箱延迟，再决定复用输出流 | 待测；软件时间戳不等同声学首声 |
| 合计 | 2.00 s | 各阶段联合验收 | 尚未达到/尚未证明 |

优先顺序：

1. 常用控制指令先走本地工具捷径，不等待大模型生成；固定确认音在就绪前缓存。本次已实现音量工具，仍须承担结束判定与识别延迟。
2. 在额定频率与原线程设置下，使用相同录音、相同seed、相同上下文，对照 `--first-clause-chars 8`、`12`、`16`。听完整性与分段断音，不能只看首声。该选项针对中文；英文仍按标点切分。
3. 如果识别耗时显著，评估 sherpa-onnx 的真正流式识别模型，使识别与用户讲话重叠；不能把现有 SenseVoice 改个名称就称为流式。中英文质量、内存与额外CPU争用必须复测。
4. 首token慢则检查prompt处理与上下文缓存；不要盲目提高全部线程数。现有2线程生成/8线程输入处理作为对照基线。
5. 首段合成慢再比较音色/模型。Qwen3-0.6B既往质量未过线，不直接换成默认模型。更换聊天或合成模型须保持原有质量门槛。
6. 如果当前A733在质量达标下仍超预算，应明确报告硬件/模型上限，再比较主机升级或联网推理；后者会改变独立离线约束，不默认启用。

## 2. 收音门槛

新的候选设置在 `fast-profile.json`：`min_input_dbfs=-38`、`min_voice_ms=120`。原RMS门槛0.004约为−48 dBFS；−38 dBFS约为0.0126，提高约10 dB。该值仅为待校准起点，可能漏掉远处或轻声说话。

这是数字满幅电平 dBFS，不是声压级 dB SPL；未经校准的USB麦克风无法据此声称“过滤40分贝以下声音”。麦克风增益改变后需要重测。持续约120毫秒超过门槛才开始收音，短促碰撞不容易误触发；保留约200毫秒前滚避免漏掉首字。进入一句话后仍保留低电平音频，不逐帧删除轻声尾音。

RMS与Silero模式均受该电平下限约束；VAD开启时仍持续喂入音频以维护状态，再与电平判定相与。响亮的非语音仍可能误触发RMS，电平门槛不能识别说话人，也不等同唤醒词。

板上停止语音服务后，先用 `robot.py --devices` 确认编号。保持与服务相同麦克风增益，分别在环境安静、目标忽略的小声、正常说话三个条件运行：

```bash
.venv/bin/python calibrate_input.py --input-device 0 --seconds 10
```

输出为20毫秒块RMS电平分位数。环境噪声P95与目标小声高位电平应低于门槛；正常说话应有连续120毫秒高于门槛。两者重叠则仅靠单一电平无法可靠分开，需要调整距离、增益、指向性或加入唤醒机制。

临时覆盖示例（数值越接近0越严格）：

```bash
.venv/bin/python run_fast.py --language zh --min-input-dbfs -38 --min-voice-ms 120
```

若同时传入 `--threshold`，dBFS参数优先。配置中保留旧threshold供回溯；要回退，移除新增两项可恢复旧门槛，起音默认仍为120毫秒，可显式指定 `--min-voice-ms 60` 恢复旧起音要求。

## 3. 音量工具：识别 → 执行 → 回执

`voice_controls.py` 提供白名单工具 `set_volume`，在ASR之后、聊天模型之前处理。命中完整指令后实际调整播放信号幅度，不仅返回‘好的’。工具结果含 before、percent、ok，写入原JSONL日志；不执行任意Shell，不让模型文本直接成为系统命令。

| 可直接说的话 | 动作 |
|---|---|
| 声音小一点 / 请小声一点 / 调低音量 / turn down the volume | 应用音量下降20个百分点，最低0 |
| 声音大一点 / 调高音量 / turn up the volume | 上升20个百分点，最高100 |
| 音量调到30% / set volume to 30 percent | 应用信号幅度设为30% |
| 静音 / mute | 设为0，不再可听到确认音 |
| 取消静音 / unmute | 恢复静音前非零音量 |

百分比指软件信号幅度，不是响度百分比，也不是ALSA滑块。服务原有硬件70%仍为上限基础；不会额外放大超过原幅度。语音、确认音与后续会话提示音使用当前应用音量，静音不停止收音。会话超时/重开保留音量；进程重启恢复100%，尚无跨重启持久化。

完整话语白名单避免把‘不要调低音量’、‘如何调低音量’或模型生成的句子误执行。当前支持表内有限表达，未实现任意自然语言计划、多工具推理、中文数字‘百分之三十’或混合请求。它是可扩展的本地工具执行起点，不称为通用agent。
