## 接线与首次上电

1. 等电脑端回读结束后，安全弹出读卡器，取出 SD 卡。Windows 若提示格式化，选择取消。
2. 保持香橙派断电，装好散热片并插入 SD 卡。
3. 用 HDMI 线连接香橙派与独立显示器的 HDMI 输入口。
4. USB 键盘插到香橙派。暂按最小配置验证主机启动，录放音测试时再接麦克风和音箱。
5. 显示器选择对应的 HDMI 输入源，最后给香橙派接上电源。
6. 等待启动完成。首次启动会自动扩展根分区，期间保持供电。出现 `login:` 提示后进入登录步骤。

香橙派直接从 SD 卡上的系统启动。板卡实际启动、自动扩容和硬件识别以屏幕与命令输出为准。

## 登录并检查系统

该官方镜像的初始账号为 `orangepi`，初始密码为 `orangepi`。输入密码时，终端通常不显示字符，输入完成后按 Enter。若系统要求首次修改密码，按屏幕提示完成；否则登录后运行 `passwd` 修改。

登录后逐条运行下面的命令，并留存实际输出。

```bash
uname -m
tr -d '\0' </proc/device-tree/model
echo
cat /etc/os-release
python3 --version
df -h / ~
free -h
```

预期识别为 Orange Pi 4 Pro、`aarch64`、Debian 12 和 Python 3.11。检查根分区是否已利用这张 64GB 卡的可用容量，传部署包前确认家目录所在分区至少有 6GB 空闲。容量显示会受到单位换算和系统占用影响。

## 没带网线时配置 Wi-Fi

先用显示器和键盘登录，在香橙派终端运行下面的命令。

```bash
sudo nmtui
```

1. 用方向键选择 `Activate a connection`，按 Enter。
2. 选择自己的 Wi-Fi，按 Tab 移到 `Activate`，按 Enter。
3. 在板端输入 Wi-Fi 密码，按 Enter 连接。
4. 已连接网络前出现 `*` 后退出，选择 `Back`、`Quit`。
5. 用下面的命令查看网卡状态和 IPv4 地址，记录已连接无线接口的地址。

```bash
nmcli device status
ip -4 -br address
```

让 Y9000P 连到同一个可互通的 Wi-Fi，再在笔记本 PowerShell 执行下面的命令。

```powershell
$boardIp = Read-Host '输入香橙派无线接口的 IPv4 地址'
Test-NetConnection -ComputerName $boardIp -Port 22
ssh "orangepi@$boardIp"
```

首次 SSH 提示主机身份时，先核对连接的 IP，并可在板端用 `ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub` 对照指纹。登录后再次核对板型和系统。两台设备连上同一个 Wi-Fi 后仍不通时，检查是否是开启设备隔离的访客网络。

Wi-Fi 配置采用用户提供的中文手册 v1.4 §3.7.2.2，初始 SSH 账号采用 §3.8。对应 PDF 页码为 71–73、93。

## 排障与关机

| 现象 | 首先检查 |
|---|---|
| 显示器无画面 | 输入源、HDMI 两端连接、板端供电和 SD 卡是否插稳。记录屏幕提示及板上指示灯状态。 |
| 有启动信息但还没到登录提示 | 保持供电，观察启动输出，记录最后的停留位置。 |
| 密码输入看不见 | 输入后按 Enter，终端隐藏密码字符属于正常行为。 |
| SSH 连接不上 | 重新确认板端无线 IP、笔记本所在网络、TCP 22 是否可达。 |
| Windows 不显示卡内文件或提示格式化 | 取消格式化，卡内已有 Linux ext4 系统分区。 |

需要关机时，在香橙派终端运行 `sudo poweroff`，确认系统已停机后再断开电源。
